# 침몽도시: 루시드 다이버 — 발표 체크리스트

> ⚠️ **발표 당일 현장에서 발표 시작 30분 전에 반드시 검수해야 하는 항목입니다.**
> 본 프로젝트는 인터넷 연결이 차단된 오프라인 환경에서도 완벽히 실행되도록 제작되었습니다.

---

## 1. 발표 전 장비 및 환경 확인

- [ ] **브라우저 실행 확인**:
  - `presentation/index.html` 파일을 더블클릭하여 Chrome, Edge 또는 Safari 브라우저에서 잘 열리는지 확인합니다.
  - 별도의 서버 구동 프로그램이나 터미널 명령어(npm run dev 등) 없이 바로 브라우저에 화면이 나오는지 확인합니다.
- [ ] **전체 화면 진입 테스트**:
  - `F` 키를 눌러 브라우저 전체 화면 모드가 정상 기동되는지 확인합니다.
  - 또는 마우스 우측 상단 메뉴를 통해 전체 화면으로 진입할 수 있는지 확인합니다.
- [ ] **해상도 및 잘림 현상 확인**:
  - 발표 스크린에 화면이 꽉 차는지, 레터박스가 적절히 적용되어 텍스트나 핵심 UI가 화면 바깥으로 잘려나가지 않는지 검수합니다. (기준 해상도: 1920×1080)
- [ ] **인터넷 차단 상태 테스트**:
  - 랜선을 뽑거나 Wi-Fi를 끈 완전 오프라인 환경에서 파일 리로딩(새로고침)을 수행하여 폰트 및 다이어그램 등이 깨지지 않고 동일하게 표시되는지 확인합니다.

---

## 2. 미디어 및 오디오 출력 점검

- [ ] **오디오 출력 확인**:
  - 발표장 스피커와 노트북이 정상 연결되어 오디오가 출력되는지 점검합니다.
- [ ] **영상 코덱 및 재생 테스트**:
  - `assets/videos/` 폴더 내에 배치한 로컬 MP4 파일들이 버벅임 없이 자연스럽게 재생되는지 테스트합니다.
  - 권장 사양: H.264 (영상 코덱), AAC (오디오 코덱).
- [ ] **자동 재생 상태 점검**:
  - 페이지 로드와 동시에 재생되어야 하는 영상이 음소거(`muted`) 상태로 부드럽게 자동 시작되는지 확인합니다.
- [ ] **누락 에셋 및 대체 화면 확인**:
  - 이미지나 영상 경로를 잘못 입력한 경우에도 웹사이트 화면 전체가 깨지지 않고 깔끔한 회색 에러 박스와 파일명이 대신 노출되는지 임의로 점검합니다.
  - 대체 영상(대체 화면)이 정상으로 표기되는지 봅니다.

---

## 3. 발표 현장용 리소스 백업

- [ ] **USB 백업 폴더 준비**:
  - 발표용 PC 문제에 대비하여, `presentation/` 폴더 전체를 복사하여 백업 USB 드라이브에 넣어 지참합니다.
- [ ] **대체 영상 보관**:
  - 빌드 데모가 원활하지 않을 때를 대비해 실기 플레이 녹화 영상 파일을 USB 및 로컬 드라이브에 상시 대기해 둡니다.
