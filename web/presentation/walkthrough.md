# 오프라인 실행형 인터랙티브 웹 프레젠테이션 구축 완료

기존의 복잡한 React/Vite/TypeScript/JSON 기반의 개발자 협업 프레임워크를 완전히 폐기하고, 발표장에서 더블클릭 한 번만으로 안전하고 화려하게 기동되는 **단일 파일 실행형 인터랙티브 웹 프레젠테이션**을 성공적으로 구축했습니다.

---

## 1. 주요 구현 내용

### 🛠️ 기술 사양
- **완전 무중단 오프라인 구동**: 외부 CDN(웹 폰트, JS 프레임워크 등) 의존성을 100% 제거하고 시스템 폰트 스택을 탑재하여 인터넷 차단 환경 및 `file://` 로컬 프로토콜에서 완전히 오프라인으로 실행됩니다.
- **노 서버 & 빌드리스**: Node.js 서버, npm install, webpack/vite 빌드 과정이 불필요합니다. 폴더 복사 후 `index.html` 더블클릭만으로 즉각 작동합니다.
- **GPU 가속 스케일링**: 해상도 및 모니터 크기와 관계없이 발표 화면 비율(16:9)을 유지하며 브라우저 가속으로 전체 스크린을 꽉 채우는 반응형 스케일링 엔진을 탑재했습니다.

## 2. 인터랙티브 장면 및 연출 (PPT 대비 강점)

1. **Chapter 00. Opening / Scene 01 - 시스템 부팅**: 
   - 관제 시스템 부팅 문구가 타이핑 형식으로 순차 등장하며, 발표자가 클릭하면 신경 링크 접속이 체결되는 SF 연출을 제공합니다.
2. **Chapter 01. Overview / Scene 01 - 프로젝트 프로필**: 
   - 딱딱한 표 대신 정보가 텔레메트리 연출처럼 순차적으로 등장하는 기획 로그 연출을 사용합니다.
3. **Chapter 02. Challenge / Scene 01 - 장르 모순의 해결**: 
   - 캐릭터 애착(서브컬처)과 영구 소실(익스트랙션)의 대립 구조에서 기획자가 중앙의 `?` 노드를 클릭하면 `SYNC` 상태로 동기화되며 해결 패널이 열리는 인터랙션입니다.
4. **Chapter 03. Loop / Scene 01 - 핵심 플레이 루프**: 
   - 각 단계를 클릭할 때마다 실시간으로 설명과 기획 강조점이 변하며, 성공 루트(초록) 및 실패 루트(빨강)를 클릭해 직관적인 플레이 흐름의 차이를 대조할 수 있습니다.
5. **Chapter 03. Loop / Scene 02 - 기억 조각 수집**: 
   - 화면에 떠다니는 기억 조각 카드를 클릭하면 CSS 궤적을 그리며 뇌파 게이지가 채워지고, 100% 도달 시 스토리 로그 해금 피드백이 연출됩니다.
6. **Chapter 05. UI / Scene 01 - UI 기획/실현 Before-After 슬라이더**: 
   - 마우스를 이동하면 와이어프레임(Mockup) 기획 화면과 Unity 엔진 실제 렌더링 화면이 비율에 맞춰 실시간 클리핑 전환됩니다.
7. **Chapter 05. UI / Scene 02 - 로비 메타 흐름 시뮬레이터**: 
   - 로비 코어, 창고/인벤토리, 심상기록판 탭을 클릭하여 각 화면의 UI 정보 변화를 동적으로 기동해 보일 수 있습니다.

## 3. 발표 제어 단축키 가이드

| 입력키 | 동작 |
|---|---|
| `→`, `PageDown`, `Space` | 다음 장면 (Next Scene) |
| `←`, `PageUp` | 이전 장면 (Prev Scene) |
| `Home` | 첫 장면으로 이동 |
| `End` | 마지막 장면으로 이동 |
| `F` | 브라우저 전체 화면 (Fullscreen) 토글 |
| `N` | 발표 대본 (Notes) 창 토글 |
| `M` | 전체 챕터 빠른 이동 메뉴 (Chapter Menu) 토글 |
| `R` | 현재 장면의 인터랙션 상태 초기화 (Reset) |
| `D` | 제작자 전용 디버그 텔레메트리 오버레이 토글 |
| `Esc` | 오버레이 창 닫기 또는 전체 화면 해제 |

---

## 4. 제작자 전용 디버그 시스템

발표 중에 `D` 키를 누르거나 파일 경로에 `?debug=1`을 입력하면 화면 좌측 상단에 실시간 디버그 모드가 나타납니다.
- **장면 정보 텔레메트리**: 현재 위치 및 총 슬라이드 수
- **장면 속성**: CORE / DETAIL / DEMO / SKIP 구분 및 담당자
- **대기/미결정 사항 점검**: 마크다운 형태의 주석 태그 (`[TODO]`, `[INTERVIEW]`, `[ASSET]`)를 실시간 스캔하여 경고 제공
- **안정적 대체 화면**: 이미지나 비디오 로드 실패 시 화면 전체가 깨지지 않도록 SVG 에러 박스로 파일명을 시각화
