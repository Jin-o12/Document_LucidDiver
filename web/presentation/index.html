세계관 및 설정

LORE DECKS & SETTINGS

침몽도시

수면병에 빠진 인간들의 뒤섞인 꿈이 현실을 왜곡하여 잠식하는 영역.

상세 설정

왜곡된 꿈이 현실의 마트나 도시 인프라를 뒤틀어 놓아 비주얼적으로 이질적이고 몽환적인 분위기를 연출합니다.

다이버 (Diver)

왜곡된 무의식 심층까지 직접 다이브하여 실기 임무를 수행하는 요원.

상세 설정

꿈속의 시야 제한 패널티를 안고 돌발 위험에 대처해야 하며, 관제사의 정보 전송 없이는 전투 효율이 저하됩니다.

관제사 (Linker)

현실 통신부스에서 특수 장비로 다이버의 위치와 위협을 안내하는 가이드.

상세 설정

레이더와 미니맵 분석, 기믹의 패스워드 추출을 담당하며 다이버에게 음성 및 전술 알림으로 방향을 조율합니다.

기억 파편

침몽도시 내부에서 획득해야 하는 핵심 익스트랙션 리소스.

상세 설정

해당 자원을 온전히 수집해 정화한 채로 탈출해야만, 다이버와의 동조율이 상승하며 로비에서 개인 심상 기록이 해금됩니다.

UI 기획 및 실제 구현

MOCKUP VS ACTUAL WORK COMPARISON

마우스를 이미지 위에 올리고 움직여서 UI 기획 와이어프레임과 Unity 인게임 화면을 비교해 보세요.

인게임/아웃게임 UI 루프
