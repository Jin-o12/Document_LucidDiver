## 2. 대표 작업 선택

### 대표 작업 (Main Work)

**작업명**: 프로젝트 총괄 기획 & 공식 PV 트레일러 연출 & UI GUI 와이어프레임 목업 및 인게임 세션 UI 레이아웃 설계

**이 작업을 대표 사례로 선택한 이유**: 본 프로젝트가 '서브컬처 수집형 ↔ PvE 익스트랙션' 장르임을 청중에게 임팩트 있게 각인시키기 위해 공식 PV 트레일러와 *'관제사는 기록한다'* 서사를 직접 연출했으며, 초기 UI 7종 와이어프레임 시안 설계부터 로비/출격 준비 UI 및 인게임 세션 루프(진입 ➔ 파밍 ➔ 전투 ➔ 탈출 성공/실패) UI 프리팹 구축까지 루시드 다이버의 기획·비주얼 브랜딩 틀을 직접 완수했기 때문입니다.

**이 작업에서 본인이 맡은 정확한 범위**:
- **[Scene 1] 총괄 기획 & 공식 PV 트레일러 연출**: 서브컬처 장르 정체성을 알리는 인트로 컷씬 및 PV 트레일러 연출/제작, *'관제사는 기록한다'* 슬로건 수립 및 세계관 기획 원안 고정
- **[Scene 2] UI 와이어프레임 목업 & 로비/출격 준비/인게임 세션 UI**: 초기 UI GUI 7종 와이어프레임 시안 작성 (`CP_UI_Mockup_Design.png`), 로비 및 출격 준비 UI (`CP_UI_Sortie_Preparation.png`), 유니티 런타임 세션 루프 UI 프리팹 레이아웃 구축 (`CP_Session_01_Entry.png` ~ `CP_Session_05_Extraction_Failure.png`)

### 보조 작업 — 선택 (Auxiliary Work)

**작업명**: AnyPortrait 2D 캐릭터 리깅 & Live2D Cubism 일러스트 제작 & FL Studio 58종 SFX/BGM 오디오 파이프라인 구축

**선택 이유**: 2D 픽셀 캐릭터 유안(`Player_Yuan`)의 AnyPortrait 뼈대 리깅과 Live2D Cubism 일러스트 제작으로 움직임과 표현 가능성을 확인하고, Splice/ElevenLabs/Suno 소스 수집 ➔ FL Studio 후가공을 통한 58종 SFX/BGM 구축으로 장면의 감정과 피드백 방향을 들을 수 있게 했습니다. UI 목업·캐릭터 모션·오디오·PV는 서로 다른 보조 작업이지만, 추상적인 기획을 팀원이 직접 보고 듣고 판단할 수 있는 형태로 먼저 구체화했다는 공통 목적을 가집니다.

## 3. 대표 작업 설명

### 3.1 완성 결과

**작성**: 서브컬처 캐릭터 구원 서사를 바탕으로 장르 정체성을 극대화하는 공식 PV 트레일러를 직접 연출/제작하고, 초기 UI 7종 와이어프레임 시안을 수립하여 유니티 인게임 세션 UI 레이아웃의 기틀을 완성했습니다. 또한 보조 작업으로서 2D 픽셀 캐릭터 유안(`Player_Yuan`)을 AnyPortrait 툴로 리깅하고 Live2D Cubism 일러스트를 연동하였으며, FL Studio로 다듬은 58종 SFX/BGM 오디오 파이프라인을 구축해 입체적 프로토타입 기틀을 구현했습니다.

### 3.2 작업 목표

**작성**: PV 트레일러와 직관적인 UI 와이어프레임을 통해 서브컬처 게임으로서의 브랜딩과 유저 몰입감을 선제적으로 확보하고, 서브컬처 픽셀 캐릭터의 조준감과 Live2D 일러스트의 생동감, 그리고 FL Studio 58종 오디오를 유기적으로 연동하여 완성도 높은 플레이 경험을 제공하는 것을 목표로 했습니다.

### 3.3 핵심 문제 또는 제약

**작성**: ① 캐릭터 애착 ↔ 익스트랙션 손실 장르 간의 본질적 모순 조율 및 PV 트레일러를 통한 서사 직관성 전달, ② AnyPortrait 렌더러와 URP Lit Shader Graph 결합 시 알파 클리핑 영역 핑크색 에러 렌더링이 주요 기술적/기획적 제약이었습니다.

### 3.4 사용 기술과 선택 이유

**사용 기술**:
- `PV 트레일러 & 인트로 컷씬 영상 믹싱` (서브컬처 브랜딩 트레일러)
- `Clip Studio Paint` (UI 7종 와이어프레임 시안 & 픽셀 파츠 분리)
- `AnyPortrait` (2D 메시 본 리깅 및 뼈대 가중치 세팅)
- `Live2D Cubism Editor` (Live2D 캐릭터 일러스트 파츠 분리 및 파라미터 애니메이션)
- `URP Shader Graph` (Point 필터링 & 알파 클리핑 노드)
- `FL Studio` (사운드 믹싱/마스터링/후가공) + `Splice` / `ElevenLabs` / `Suno` + `AudioManager` 3D 감쇄 세팅

**선택 이유**: 서브컬처 게임임을 증명하는 PV 트레일러와 UI 레이아웃을 최우선 연출한 후, 2D 픽셀 액션 연출과 Live2D 일러스트 비주얼, FL Studio 믹싱 고품질 사운드를 동시 만족시키기 위해 PV 영상 믹싱, 와이어프레임 목업, AnyPortrait, Live2D Cubism, URP 셰이더 파이프라인 결합을 선택했습니다.

### 3.5 구현 결과

**작성**:
- **이전**: 서브컬처 장르 직관성 부재, 기획 및 시청각 리소스 부재, 정적 픽셀 이미지 상태
- **이후**: 공식 PV 트레일러 연출 완성, 서사 원안 정립, 반응형 UI 와이어프레임 및 출격준비/5단계 세션 루프 UI 구축, AnyPortrait 전방향 동적 모션 및 Live2D Cubism 일러스트 탑재, FL Studio 후가공 58종 SFX 쾌속 오디오 연동

**프로젝트에 준 도움**:
- **UI 목업**으로 구현 전에 화면 구조와 사용 흐름을 검토할 수 있게 했습니다.
- **AnyPortrait·Live2D 시안**으로 정적 원화가 실제 캐릭터 움직임과 대화 연출로 이어질 가능성을 보여주었습니다.
- **SFX·BGM 샘플**로 장면의 감정, 전투 피드백, 공간 분위기를 청각적으로 공유했습니다.
- **PV 제작**으로 흩어진 서사·캐릭터·게임플레이·오디오의 방향을 하나의 시청각 경험으로 정리했습니다.
- 각 분야의 전문 작업을 대신하는 것이 아니라, 팀원이 구현할 결과를 같은 방향으로 상상하고 사전에 판단할 수 있는 **커뮤니케이션용 프로토타입**을 제공했습니다.

### 3.6 남은 한계 또는 개선점

**작성**: 향후 다종 다이버 캐릭터 추가 시 PSD 파츠 분리 및 메시 리깅 작업 공수를 자동화할 파이프라인 고도화가 필요합니다.
