# 1. 플레이어 캐릭터

## 1.1. 오브젝트 구성 (P0)

- 플레이어 캐릭터 오브젝트는 이하의 하위 오브젝트로 구성된다.

    - 위치 기준점 (Transform): 플레이어의 위치 및 방향(Y 위, Z 정면) 정보를 계산하는 기준점.

    - 몸통 (Collider): 플레이어↔적, 플레이어↔장애물 간의 접촉 상호작용 발동 여부를 판정하는 기준 영역.

        - 장애물 판정을 위해 Trigger 설정을 비활성화한다.

    - 상호작용 구역 (Collider): 플레이어↔상호작용 가능 오브젝트(무장, 회수품) 간의 상호작용 UI 출력 여부를 판정하는 영역.

        - Trigger 설정을 활성화하여 사용한다.

    - 손 (Transform): 무장 아이템 장착 시 무장 오브젝트가 배치되는 위치 기준점.

    - 공격 방향(vector3): 위치 기준점을 시작점, 손을 끝점으로 하는 방향 벡터.

        - Y축 값을 0으로 초기화한 후 길이 Normalize를 적용하여 사용한다.

## 1.2. 플레이어 상태 (P0)

- 플레이어 캐릭터는 bool 또는 enum으로 표기되는 상태 값을 갖는다.

    - 재장전 중(`isReloading` : bool): 플레이어가 탄창을 전부 사용하여 재장전 상태인지 확인

    - 생존 상태(`livingState` : enum): 플레이어의 메인 캐릭터 상태를 확인

        - 0: idle `기본` (P0)

        - 1: escape`탈출 중` (P0)

        - 2: gameover `강제각성` (P0)

        - 탈출 조건 우선 순위는 enum 오름차순으로 판정한다(탈출 중 → 강제각성 순서로 처리)

## 1.3. 플레이어 조작

### 1.3.1. 이동

- **PC (키보드+마우스) 조작 (P0)**: WASD 및 화살표(↑←↓→) 조작을 사용해 XZ 평면상에서 8방향 2.5D 캐릭터 이동을 처리한다.

- **모바일 (터치패드) 조작 (확장)**: 화면 왼쪽의 가상 조이스틱 드래그 벡터에 기반하여 플레이어 캐릭터의 실제 이동을 처리한다.

### 1.3.2. 기본 공격

- **PC (키보드+마우스) 조준 및 격발 (P0)**: 마우스 왼쪽 버튼 클릭으로 홀드하여, 플레이어 위치 기준점과 클릭 지점 사이의 방향 벡터를 기본 공격 명령 값으로 입력한다. 공격 방향 벡터 방향으로 무장의 발사 가능 사거리 길이만큼 공격 Ray를 출력하여 적 피격 Collider에 접촉 시 기본 공격 루틴을 실행한다.

- **모바일 조작 (확장)**: 화면 오른쪽의 가상 조이스틱을 드래그하여 공격 명령을 입력한다.

- 기본 공격 제한 조건 (P0):

    - 장착 중인 무장이 없는 경우

    - `재장전 중==true` 상태인 경우

    - 플레이어가 보유한 마나가 기본 공격에 필요한 마나 미만인 경우

    - 이전 기본 공격 루틴 1회 실행 후 경과한 시간이 발사 간격 시간 미만인 경우

### 1.3.3. 오브젝트 상호작용 (P0)

- 플레이어 캐릭터의 상호작용 구역 Collider에 상호작용 가능한 오브젝트의 Collider가 접촉하면 상호작용 버튼이 오브젝트의 정해진 위치에 출력된다.

- 상호작용 버튼이 출력된 상태에서 이하의 조작을 통해 해당 오브젝트와 상호작용을 실행한다.

    - PC: Input System에 등록한 상호작용 키를 입력

    - PC/모바일: 상호작용 버튼을 터치(PC 환경에서는 마우스 클릭)

## 1.4. 마나 (P0 / MVP 분리)

- 기본 공격, 메인 캐릭터 스킬, 지원 캐릭터 호출을 사용하는 데에 소비되는 자원.

- 월드 진입 시 최대 100을 보유하며, 매 초마다 정해진 `초당 마나 회복` 수치만큼 자동으로 회복된다.

- 기본 공격 시 장착한 무장의 종류에 따라 정해진 수량만큼 마나가 소비된다.

  - **에너지 권총 (pistol)**: 1 마나 소모 (P0 - 필수)

  - 해머, 샷건, 저격소총, 지정사수소총, 기관단총, 로켓런처, 방패권총: (MVP / 확장 - 1차 빌드 제외)

- 메인 캐릭터 특수 스킬 발동 시 20 마나 소비 (MVP)

- 지원 캐릭터 호출 시 20 마나 소비 (MVP)

## 1.5. 지원 캐릭터 (MVP / 확장)

- 메인 캐릭터 이외에 추가로 편성 가능한 캐릭터. (1차 프로토타입 범위 제외)

### 1.5.1. 심상 공명 (MVP / 확장)

- 캐릭터들의 역할/기물/소속 태그 조합에 따른 패시브 효과. (1차 프로토타입 범위 제외)

# 2. 맵 설정

## 2.1. 카메라 설정 (P0)

- 메인 카메라에 Cinemachine을 적용하여 플레이어 메인 캐릭터 Transform을 Follow 및 LookAt 대상으로 지정한다.

## 2.2. 시작 지점 (P0)

- 각 맵마다 정해진 위치에 시작 지점(EntryPoint)을 설정하여 플레이어 캐릭터가 최초 소환되도록 처리한다.

## 2.3. 탈출 지점

- **프로토타입 간이 탈출 (P0)**: 플레이어의 몸통 Collider와 탈출 지점의 Collider가 접촉하는 즉시 성공 탈출 판정을 실행한다. (채널링 시간 = 0)

- **정식 탈출 (MVP)**: 플레이어가 탈출 지점에 머물며 3초간 채널링(수화기를 귀에 대는 동작) 상태를 유지해야 탈출을 완료한다. 중도 이탈 시 취소된다.

## 2.4. 탈출 판정 (P0 / MVP 분리)

- **실패 판정 (P0)**: 플레이어 캐릭터의 보유 체력이 0 이하가 되면 `강제 각성` 상태로 즉시 실패 처리한다.

- **정산 처리 (P0 / MVP 분리)**:

  - **프로토타입 정산 (P0)**: 획득한 `Item_Test` 수량 카운트를 정산 출력한다.

  - **정식 정산 (MVP/확장)**:

    - 기본 무장 및 보존 슬롯에 보관된 특화 무장/기물은 유지된다.

    - 일반 인벤토리에 들어있는 회수품 및 특화 무장은 탈출 성공 시 획득/유지되며, 강제 각성(탈출 실패) 시 100% 소멸된다.

    - 획득한 드림 포지드 무장은 탈출 성공 시 무장 파편 재료로 해체 분해된다.

## 2.5. 시간 차감 가속 (MVP / 확장)

- 맵 내의 정해진 구역(ZONE_MID, ZONE_CORE)에 따라 제한 시간 차감 속도가 가속되는 시스템. (1차 프로토타입 범위 제외)

# 3. 아이템

## 3.1. 아이템 생성 및 상호작용 (P0)

- 지정된 위치에 아이템이 생성되며, 플레이어가 상호작용 시 획득하여 인벤토리에 등록하고 월드 맵 오브젝트를 비활성화한다.

## 3.2. 무장

- **기본 무장 (P0)**: 에너지 권총 `희미한 잔상` 1종 제공. (발당 1 마나, 탄창 15발, 재장전 1.5초)

- **특화 무장 및 드림 포지드 무장 (MVP / 확장)**: 1차 빌드 범위 제외.

### 3.2.5. 재장전 (P0)

- 기본 공격 격발 시 현재 탄창이 차감되며 0이 될 시 `재장전 중 = true`가 되고, `재장전 시간(1.5초)` 대기 후 탄창 수량을 초기화한다.

## 3.3. 방어구 (MVP / 확장)

- 캐릭터 보호용 정신 방벽(Ego Shield) 및 방어력 계수, 정신적 과부하 페널티 시스템. (1차 프로토타입 범위 제외)

# 4. 적

## 4.1. 오브젝트 구성 (P0)

- 적 캐릭터 오브젝트는 위치 기준점 및 몸통 Collider로 구성된다.

## 4.2. 적 상태 제어

### 4.2.1. P0 필수 AI FSM (P0)

- **Idle**: 소환 위치에서 반경 12m 내에 플레이어 조작 캐릭터가 들어오는지 스캔한다.

- **Detect**: 플레이어 감지 시 타겟으로 지정하고 최단 경로로 추적한다.

- **Attack**: 플레이어가 2m 이내로 들어오면 0.5초 선딜레이 후 플레이어에게 10의 피해를 가한다. (쿨타임 2초)

- **Dead**: 체력이 0이 되면 AI를 정지하고 사망 위치에 `Item_Test` 1개를 스폰한 뒤 비활성화된다.

### 4.2.2. P0.5 선택 FSM (P0.5)

- **Hit / Groggy**: 몽막이 0이 되었을 때 넉백 및 3초간 경직 상태(경직 중 이동/공격 불가, 피해 1.5배 증가 적용)를 유지한다. 경직 시간이 지나면 Idle/Detect 상태로 복귀한다.

## 4.3. 몽막 / 심상핵 (P0.5 선택)

- 적 캐릭터의 몽막 게이지 및 몽막 붕괴(그로기 3초) 시 치명타 1.5배 피해 배율 적용, 몽막 재생 시간 대기 후 몽막 최대치 자동 회복 메커니즘. (1차 빌드 필수 검증 조건에서 제외)

# 5. 전투

## 5.1. 피해 계산

### 5.1.1. P0 필수 피해 계산 (P0)

- 플레이어 탄환이 적에게 닿으면 적 HP가 감소한다.

- 적이 공격 애니메이션 후 피해 판정 시점에 플레이어 HP를 10 감소시킨다.

- 체력이 0 이하가 되면 즉시 사망 처리를 실행한다.

### 5.1.2. P0.5 선택 피해 계산 (P0.5 / MVP 분리)

- 피격 시 몬스터 HP 감소 전에 `dreamBarrier` 수치(최대 30, 발당 10 감소)가 먼저 감소한다. (P0.5)

- `dreamBarrier`가 0이 되면 3초간 그로기 상태가 되어 피해가 1.5배(발당 15)로 가산된다. (P0.5)

- 현재 방어막이 존재할 때 방어막이 체력보다 먼저 차감되는 규칙은 MVP 방어구 시스템 도입 시 적용한다. (MVP)

## 5.2. 체력 소진 시 처리 (P0)

- 플레이어 HP 0 이하 시 `강제 각성` 세션 실패 결과창 출력.

- 적 HP 0 이하 시 사망 연출 후 필드에 `Item_Test` 1개 스폰.

# 6. UI

## 6.1. 월드 신 UI (P0 / MVP 분리)

- **P0 필수 UI**: 플레이어 체력(HP), 마나 게이지, 무장 슬롯(현재 탄창/총알 수 카운트), 우측 상단의 회수품 획득 개수 카운터, 이동/조준 가상 조작계(PC 검증용 마우스 클릭/WASD 작동).

- **MVP UI**: 캐릭터 썸네일, 적 체력 및 몽막 게이지바, 피해량 텍스트 출력 고도화.

## 6.2. 인벤토리 (P0 / MVP 분리)

- **P0 필수 인벤토리**: 별도 그리드 연산 없이 획득한 `Item_Test` 수량 카운터 텍스트로 대체 검증.

- **정식 인벤토리 (MVP)**: 

  - 일반 인벤토리는 그리드(Diablo-style) 개념을 전면 배제하고 **1칸 단위 슬롯 + 중첩(Stack) 유무** 방식으로 정리한다.

  - 슬롯 크기(`size`) 개념은 오직 **각성 보존 슬롯(2x2, 총 4칸)** 전용 규칙으로 분리하여 제한한다.

  - 보존 슬롯에 등록된 회수품 크기는 1칸(소형), 2칸(중형), 3칸(특화 무장), 4칸(보스 심상핵)으로 제한되어 안전 회수 시 전략적 공간 딜레마를 제공한다.

## 6.3. 결과 창 (P0)
