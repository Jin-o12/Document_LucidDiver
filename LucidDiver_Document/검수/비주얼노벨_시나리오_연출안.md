# 🖥️ 침몽도시: 루시드 다이버 — 프롤로그 터미널 시놉시스 연출안 v1.3

> **"다이버는 잊는다. 관제사는 기록한다. 그리고 다시, 구하러 들어간다."**  
> 본 문서는 웹 포트폴리오의 **[시나리오]** 섹션에 탑재할 단일 화면 터미널 시놉시스 연출안입니다.  
> 모바일/웹 환경에서 오작동할 우려가 있는 오디오 사운드를 전부 배제하고, **CSS와 Javascript로 100% 제어 가능한 강력한 시각 연출(글리치, 진동, 오버레이, 게이지 등)** 중심의 내러티브 연출로 고도화되었습니다.

---

## 1. 연출용 CSS 클래스 명세
개발 시 활용할 전용 CSS 효과 목록입니다.
*   `.scanlines`: 화면 전체에 브라운관 모니터 같은 수평선 노이즈가 스크롤되는 연출.
*   `.screen-shake`: 오염도 임계 초과 시 화면 전체를 격렬하게 무작위로 흔드는 애니메이션 (`@keyframes shake`).
*   `.text-glitch`: 텍스트가 지지직거리며 붉은색/푸른색 잔상으로 쪼개지는 연출.
*   `.alarm-overlay`: 화면 전체가 붉은빛으로 서서히 호흡하듯 명멸하는 경보 효과.
*   `.flash-white`: 화면 전체가 순간적으로 눈부시게 밝아졌다가 어두워지는 폭발 연출.
*   `.fade-in-logo`: 검은 암전 속에서 메인 타이틀 로고가 서서히 선명해지는 연출.
