# 《침몽도시: 루시드 다이버》 P1 UI/UX 종합 기획 및 명세서 (v1.0)

본 문서는 P0.5 알파 빌드의 **실제 구현 현황(교차검증 보고서 기준)**과 P1 빌드의 **핵심 연동 사양(베타 빌드 통합 정의서 기준)**을 상호 교차 분석하여, 개발팀과 외부 디자이너가 즉시 적용 가능한 수준으로 작성한 **P1 기준 UI/UX 종합 기획 및 명세서**입니다.

---

## 1. 기획 의도 및 핵심 가치 (Design Intent)

*   **비주얼/UX 고도화**: P0/P0.5 단계에서 작동성이 검증된 시스템 UI 상의 임시 와이어프레임 에셋을 100% 정식 리소스로 전면 교체하여 사용자 경험(UX)을 완성한다.
*   **어두운 꿈의 도시 테마 구축**: 툰 셰이더(Flat Kit), 세미 픽셀화 포스트 프로세싱, 그리고 원추형 손전등 시야 마스킹 연동을 통해 인게임 플레이 중 긴장감을 극대화하는 UI/UX 피드백을 전달한다.
*   **서브컬처 교감 강화**: 아웃게임 영역(로비, 다이버 기록)에서 다이버 캐릭터의 성장(동조율 레벨)에 따른 반응형 터치 리액션 및 컷신 백로그 시스템을 구축하여 캐릭터 몰입도를 극대화한다.

---

## 2. 실제 구현 기반 UI/UX 현황 분석 (P0.5 교차검증 보고서 반영)

실제 유니티 씬 및 코드 분석을 기반으로 한 현재 UI/UX 현황과 P1 진입 전 해결 조건입니다.

### 2.1 실제 구현된 UI 프리팹 목록
*   `Canvas-Lobby.prefab` (로비 메인 UI)
*   `Canvas-StorageInventory.prefab` (창고/인벤토리 UI)
*   `Canvas-SortiePrepare.prefab` (출격 준비 UI)
*   `Canvas-GameUI.prefab` (인게임 HUD UI)
*   `Canvas-timer.prefab` (탈출 채널링 타이머 UI)
*   `Canvas-ResultPanel.prefab` (결과 정산 UI)
*   `Canvas-DiverRecord.prefab` (다이버 기록/심상 기록 UI)
*   `Canvas-RecordCardPopUp.prefab` (심상 기록 대사 감상 팝업 UI)
*   `Canvas-ChestUI.prefab` (상자 파밍 팝업 UI)

### 2.2 현 구현과 기획 불일치 및 UI 버그 해결 사양
*   **소지품 퀵슬롯 규격 통일**: 기획서상 소지품 퀵슬롯은 2칸으로 되어 있으나, 유니티 실제 구현(`PlayerInventory.quickSlots[0..2]`)은 **3칸**으로 스크립트 및 프리팹이 조립되어 있습니다. **P1 빌드는 실제 구현된 3칸 슬롯을 기준**으로 UI를 구성합니다.
*   **동조율 로비 동기화 및 영속성 보장**: 로비 복귀 또는 앱 재시작 시 동조율 레벨이 0으로 초기화되는 버그(QA-CD-002, 005)와 `hasNewMemoryLog` 영속성 누락을 해결하기 위해, 저장 데이터(`PlayerSaveData`) 로드 즉시 로비 상단 및 다이버 카드 내 동조율 슬라이더에 실시간 바인딩되도록 UX 동기화 처리를 우선적으로 수행합니다.
*   **결과창 입력 차단**: 탈출 성공/실패 결과 정산 창이 떠 있는 상태에서 인벤토리 단축키(I, Tab)를 누르면 결과창 뒤로 인벤토리가 열려 UI가 고장나는 현상(QA-TD-003)을 방지하기 위해, 결과창 활성화 시 인게임 조작 및 단축키 입력을 원천 차단(Input Block)합니다.

## 3. P1 UI/UX 핵심 시스템 명세

베타빌드 통합 정의서에 규정된 P1 전용 UI/UX 시스템의 세부 동작 조건 및 연출 명세입니다.

### 3.1 툰 셰이더 및 세미 픽셀화 그래픽 연동 UX
*   **3D 월드-2D 캐릭터 조화**: 쿼터뷰/탑다운 뷰 전투 지형에 외곽선(Outline)과 2단계 셀 셰이딩(Cel Shading)을 적용하여 2D 캐릭터 스프라이트 애니메이션과의 비주얼 이질감을 제거합니다.
*   **세미 픽셀화 렌더링**: URP Post Processing을 활용해 렌더링 해상도를 낮춰 픽셀 격자 톤을 유도하며, HUD 및 폰트 레이어는 픽셀 렌더링 영역에서 제외하여 텍스트의 가독성(Sharpness)을 절대적으로 유지합니다.

### 3.2 원추형 시야 마스킹 및 손전등 광원 피드백 UX

```
┌────────────────────────────────────────────────────────┐
│                        사각지대                         │
│                    (완전 어둡게 마스킹)                   │
│          적/상자 비가시화 (Culling & Masking)            │
│                       ┌───────┐                        │
│                       │  적A  │ (보이지 않음)            │
│                       └───────┘                        │
│                 ━━━━━━━━━━━━━━━━━━━━━                  │
│               ▲                                        │
│             ▲                                          │
│           ▲   [ 손전등 Volumetric Spot Light ]         │
│         ▲        정면 부채꼴 영역 가시 구역               │
│       ▲    ┌───────┐                                   │
│     ▲      │  적B  │ ◀ 빛이 닿아 정상 노출됨              │
│   ▲        └───────┘                                   │
│ ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ │
│                     [ 다이버 유안 ]                      │
└────────────────────────────────────────────────────────┘
```

*   **동적 컬링**: 플레이어가 서 있는 정면 원추형 시야각(Fog of War) 영역 외부의 암흑 지역에 존재하는 적(Enemy)과 상호작용 기물(Chest)은 화면 상에서 실시간 렌더링 마스킹 처리하여 보이지 않게 감춥니다.
*   **손전등 빔 피드백**: 마우스 조준 방향을 실시간으로 추적하여 손전등 빔 형태의 광원 시각 효과(Spot Light)를 지면에 투사하며, 이 투사 영역 내부에 진입한 적/기물만 페이드인(Fade-in) 형태로 가시화 처리합니다.

### 3.3 로비 상호작용 및 동조율 기반 반응형 말풍선 UX
*   **다이버 WebP Idle 루프**: 로비 중앙 다이버는 투명 배경의 WebP 루프 애니메이션 포맷(`Lobby_Idle_Yuan.webp`)을 출력하여 고품질의 애니메이션을 연출합니다.
*   **캐릭터 터치 리액션**:
    *   다이버의 터치 영역(Hitbox Collider) 마우스 클릭 시 트리거.
    *   `linkRateLevel (int)` 수치에 매핑된 단계별(Lv.0 ~ 2) 대사 테이블에서 무작위 3종 중 1종을 로드하여 다이버 옆 말풍선 UI에 표출.
    *   **말풍선 타이머**: 말풍선은 0.2초간 페이드인 출력된 후 3.0초간 유지되며, 이후 0.5초간 페이드아웃됩니다. 노출 중 재클릭 시 텍스트가 즉시 갱신되며 3.0초 노출 타이머가 재시작됩니다.

### 3.4 비주얼노벨식 심상기록 컷신 및 백로그 UX
*   **진입점**: 로비 ➔ 다이버 기록 ➔ 해금된 개인 심상 기록 카드 클릭 시 진입.
*   **대화창 연출**: 화면 하단 반투명 대화창 패널에 발화자 이름, 대사 텍스트가 초당 25자 속도로 순차 출력(Typing Effect)되며, 마우스 왼쪽 클릭 시 즉시 완성형 텍스트로 노출됩니다.
*   **백로그 (Backlog) 스크롤**:
    *   텍스트 출력 화면 중 마우스 휠 스크롤 업(Wheel Up) 입력 또는 화면 내 [Log] 버튼 터치 시 활성화.
    *   현재까지 진행된 스토리 대화 로그가 역순으로 세로형 스크롤 뷰를 통해 팝업창 형태로 조회 가능합니다.
*   **스킵 (Skip) 연동**: 최초 진입이 아닌 경우 우상단 [SKIP] 버튼을 노출하며, 터치 시 즉시 컷신을 닫고 이전 목록 화면으로 안전하게 복귀시킵니다.

### 3.5 신규 튜토리얼 및 키캡 가이드 UX
*   **최초 기동 분기**: 최초 실행 플래그 `isFirstPlay` 검사 후 최초 재생 인트로 컷씬의 스킵 또는 완료 시점에, 세이브 데이터의 `isTutorialCompleted` 값을 확인하여 `false`인 경우 로비 씬을 우회하고 즉시 튜토리얼 씬(`TutorialScene`)으로 진입합니다.
*   **키캡 스타일링**: 조작 안내 텍스트 내 주요 단축키(`W`, `A`, `S`, `D`, `Shift`, `F`, `L-Click`)는 별도의 네온 블루 테두리가 들어간 키캡 형태로 시각적 차별화를 줍니다.
*   **공간 조명 가이드**: 가이드 지점으로의 이동을 안내할 때, 지면의 목표 영역에 부채꼴 하이라이트 투사 조명을 비추어 공간적 가이드라인을 제공합니다.

## 4. 정산 성공/실패 결과 화면 UI/UX 연출 규칙

P0.5 결과 정산 시스템(`ResultManager.cs`)의 탈출 성공/실패 조건 분기에 따른 연출 세부 사양입니다.

### 4.1 탈출 성공 (SUCCESS) 연출
*   **배경 및 비주얼**: 어두운 심전도 그리드 배경 오버레이(`UI_TextBox.png`) 위에 상단 중앙 녹색 네온 띠의 `MISSION COMPLETE` 타이틀 배너 출력. 캐릭터 스탠딩은 유안의 기본형 `Yuan_ST.png` 출력.
*   **기록 복구 롤링**: 사용한 기억 파편 개수와 동조율 레벨 게이지 바(`UI_SliderBar_2.png`)가 차오르는 애니메이션을 실시간 출력.
*   **회수품 보존**: 우측 획득물 슬롯에 정산 완료된 아이템 아이콘이 배치되며, 하단에 녹색의 '창고로 보존 완료' 텍스트 출력.
*   **다이버 귀환 대사**: 하단 대사창에 유안의 안도하는 귀환 대사 출력.

### 4.2 강제 각성 (FAILED) 연출
*   **배경 및 비주얼**: 적색 글리치 효과 및 `CONNECTION LOST` 타이틀 배너 출력. 캐릭터 스탠딩은 상처입은 버전(`Chaerin_DreamScar.png` 참고안) 또는 유안 스탠딩에 명도를 40% 낮춘 어두운 필터를 씌워 대체 출력.
*   **기록 유실**: 중앙 기록 복구 창에 '기억 파편 유실', '동조율 변화 없음' 텍스트를 정적인 적색으로 출력.
*   **회수품 유실 및 LOST 스탬프**: 
    *   획득했던 회수품 목록 그리드의 모든 아이콘 이미지는 **흑백(Grayscale)**으로 블러 처리.
    *   각 아이템 슬롯 중앙에 비스듬히 찍히는 **붉은색 반투명 LOST 도장 스탬프** 리소스를 오버레이하여 유실 상태를 시각적으로 직접 전달.
*   **다이버 실패 대사**: 하단 대사창에 미안해하는 유안의 실패 대사 출력.

## 5. P1 해상도 기준 화면 영역 배치 비율

1920×1080 FHD 해상도를 기준으로 개발 시 레이아웃 그룹의 정렬 기준이 되는 5대 영역의 비율 규칙입니다.

```
| 화면 영역 | 가로 너비 (W) / 세로 높이 (H) | FHD 픽셀 기준 크기 | 주요 배치 구성 요소 |
| :--- | :--- | :--- | :--- |
| **상단 영역** | 가로 100% / 세로 8% ~ 12% | W: 1920px, H: 86px ~ 130px | 게임 로고, 재화 정보, 뒤로가기/옵션 버튼 |
| **좌측 영역** | 가로 12% ~ 18% / 세로 60% | W: 230px ~ 345px, H: 648px | 관제사 정보 보드, 다이버 목록, 탭 메뉴 |
| **중앙 영역** | 가로 50% / 세로 83% | W: 960px, H: 900px | 다이버 전신, 인게임 액션 영역, 튜토리얼 팝업 |
| **우측 영역** | 가로 22% ~ 30% / 세로 60% | W: 422px ~ 576px, H: 648px | 상세 능력치 보드, 창고/인벤토리 슬롯 그리드 |
| **하단 영역** | 가로 100% / 세로 10% ~ 15% | W: 1920px, H: 108px ~ 162px | 대사창, 단축키 액션바, 소모품 퀵슬롯 |

*이 비율은 해상도 변경 대응 시 UI Canvas Scaler의 Match Mode를 Width (1.0) 또는 Height (1.0)로 조율하는 가이드라인이 됩니다.*
