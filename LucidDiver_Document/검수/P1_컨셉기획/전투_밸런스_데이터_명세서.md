# 전투_밸런스_데이터_명세서

## 0. 기획 의도 (Design Intent)
* **목표**: 플레이어 캐릭터의 조작감 및 몬스터 전투 난이도의 불합리함을 해소하고, 데이터 기반으로 수치를 신속하게 튜닝할 수 있는 파이프라인을 다진다.
* **핵심 가치**: 캐릭터 기본 능력치, 17개 스폰 구역 가중치, 아티팩트 드롭 테이블 수치를 데이터 시트로 구조화하고 JSON 연동 룰을 확정한다.

## 2. 상세 밸런싱 데이터 명세

### 2.1 플레이어 캐릭터 기본 전투 계수
각 다이버 캐릭터별 기본 스펙 및 단일 권총(Pistol) 격발 밸런스 규칙이다. 본 게임은 별도의 탄창/재장전 시스템 없이 MP(마나) 소모 기반 격발로 작동한다.

| 변수명 (Key) | 타입 | 설명 | 기본값 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| `maxHp` | `float` | 최대 체력 수치 | `100.0` | 피격 시 감소 |
| `maxMp` | `float` | 최대 마나 수치 | `50.0` | 공격 및 스킬 사용 시 소모 |
| `mpRegen` | `float` | 초당 자연 마나 회복량 | `1.0` | 전투/대기 공통 |
| `moveSpeed` | `float` | 기본 이동 속도 (WASD) | `5.0` | 달리기 시 1.5배 |
| `weaponDamage` | `float` | 발당 기본 공격력 | `10.0` | 타격 시 대상 HP 차감 |
| `mpCostPerShot` | `float` | 발당 MP 소모량 | `2.0` | 격발 시 차감 (MP 부족 시 발사 불능) |
| `fireRate` | `float` | 초당 발사 속도 (연사력) | `0.1` | 연사 시 격발 간격 시간 (초) |

---

### 2.2 마트 레벨 17개 스폰 구역 및 가중치 규칙
마트 지형 내 배치되는 17개의 몬스터 스폰 포인트에 배정될 등급별 가중치 테이블이다.

| 스폰구역 ID | 구역 성격 | 일반 몬스터 가중치 | 엘리트 몬스터 가중치 | 보스 몬스터 가중치 |
| :--- | :--- | :--- | :--- | :--- |
| `SP_ZONE_01` | 마트 입구 A | `90` | `10` | `0` |
| `SP_ZONE_02` | 야외 주차장 | `95` | `5` | `0` |
| `SP_ZONE_03` ~ `07` | 마트 1층 가전/완구 코너 | `80` | `20` | `0` |
| `SP_ZONE_08` ~ `12` | 마트 2층 식료품 코너 | `70` | `30` | `0` |
| `SP_ZONE_13` ~ `16` | 지하 주차장 창고 | `50` | `50` | `0` |
| `SP_ZONE_17` | 마트 중앙 하이퍼 코어 (보스룸) | `0` | `0` | `100` |

---

### 2.3 아티팩트 드롭률 테이블
상자 개방 시 출력되는 드롭 등급 확률 명세이다.

| 아티팩트 상자 등급 | 일반(Common) 확률 | 희귀(Rare) 확률 | 영웅(Epic) 확률 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 일반 상자 (`Box_Normal`) | `85.0%` | `14.0%` | `1.0%` | 마트 1층 기본 배치 |
| 중급 상자 (`Box_Middle`) | `50.0%` | `45.0%` | `5.0%` | 마트 2층/지하 배치 |
| 유물 상자 (`Box_Artifact`) | `0.0%` | `70.0%` | `30.0%` | 보스 처치 시 탈출구 활성화 보상 |

## 3. 데이터 파이프라인 연동 규칙

기획 엑셀 테이블은 빌드 프로세스를 통해 JSON 포맷으로 빌드되며, 유니티 에셋 폴더 하위에 위치하여 어드레서블(Addressables) 시스템을 통해 런타임에 호출된다.

* **엑셀 파일 보관소**: `/Database/ExcelSources/`
* **빌드 스크립트 실행 트리거**: Unity Editor 메뉴의 `Tool/DiverDatabase/BuildAll` 실행
* **최종 JSON 빌드 출력 경로**: `Assets/08_ExcelData/Resources/`
* **JSON 파일 명명**: `Table_[TableName].json` (예: `Table_DiverData.json`)
