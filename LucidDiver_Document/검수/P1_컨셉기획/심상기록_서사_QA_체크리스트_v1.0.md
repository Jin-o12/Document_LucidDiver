# ✅ 심상기록 서사 QA 체크리스트 (v1.0)

> [!IMPORTANT]
> 본 문서는 심상기록 대사를 작성·수정할 때 서사적 정합성을 검증하기 위한 체크리스트입니다.
> 각 기록 카드를 신규 작성하거나 개정할 때 이 리스트를 실행합니다.

---

## 1. 세계관 규칙 정합성

- [ ] **기억 손실 규칙 준수**: 해당 기록의 시점에서 유안이 무엇을 기억하고 무엇을 잊었는지가 [관제사_설정_정의서](file:///c:/Project/Document_LucidDiver/LucidDiver_Document/검수/P1_컨셉기획/관제사_설정_정의서.md) §3의 3단계 규칙과 일치하는가?
- [ ] **링크 잔향 용어 준수**: "무의식의 기억", "본능적 기억" 등의 비공식 표현 대신 **"링크 잔향(Link Echo)"** 용어를 사용하고 있는가?
- [ ] **관제 기록과 기억 파편 구분**: 심상기록 복구의 두 재료(관제 기록 = 외부 데이터, 기억 파편 = 내부 데이터)를 혼동하지 않았는가?
- [ ] **동조율 정의 준수**: 동조율을 호감도나 애정 수치가 아닌 링크 안정성 + 자아 복원도 + 기억 파편 복원 가능성의 복합 수치로 사용하고 있는가?
- [ ] **용어 통일**: "출격/진입" (O), "하강/잠수" (X) / "도시 내부" (O), "물속/심해" (X) 를 준수하고 있는가?

---

## 2. 관계 윤리 및 캐릭터 주체성

- [ ] **유안의 주체성**: 유안이 관제사에게 모든 판단을 맡기는 수동적 태도를 보이지 않는가?
- [ ] **관제사의 결점 인지**: 관제사가 지나치게 완벽한 보호자로 묘사되지 않았는가? 죄책감, 통제 욕구, 과거 집착 등의 결함이 적절히 암시되어 있는가?
- [ ] **과거 강요 금지**: 관제사가 "과거의 너는 나를 믿었다"는 사실을 현재 유안에게 압박 수단으로 사용하지 않는가?
- [ ] **독점적 표현 제한**: "유일한 빛", "유일한 존재", "버림받으면 소멸" 같은 독점적 표현이 과도하게 사용되지 않았는가?
- [ ] **연애 구도 지양**: 대사가 연인 간의 고백이나 독점적 사랑 관계로 읽히지 않는가?

---

## 3. 감정선 및 서사 구조

- [ ] **감정 단계 적합성**: 해당 기록의 관계 밀도가 이전/이후 기록과 비교하여 자연스럽게 진행되는가?
- [ ] **첫 기록(01) 거리감**: 첫 만남 기록에서 유안이 관제사를 처음부터 깊이 신뢰하지 않는가?
- [ ] **은유 중복 방지**: 한 기록 안에서 주도 은유가 하나로 통일되어 있는가? 다른 기록의 은유를 반복하지 않는가?
- [ ] **강한 문장 절제**: 서사적 결정적 순간에만 강한 문장(맹세, 절대적 약속)이 사용되었는가?
- [ ] **한 대사 하나의 감정**: 각 페이지가 하나의 감정이나 정보만 전달하고 있는가?
- [ ] **모티프 연결**: 이전 기록에서 남긴 모티프가 다음 기록에서 자연스럽게 회수되고 있는가?

---

## 4. 멀티 다이버 확장성

- [ ] **유안 고유성 보존**: 유안의 특별함이 "관제사와 가장 가까운 다이버"가 아닌 "최초의 불완전 귀환 성공자"와 "링크 잔향의 최초 사례"로 정의되어 있는가?
- [ ] **범용성 확인**: 이 기록의 관계 패턴이 다른 다이버에게 그대로 복사되어도 어색하지 않은 수준인가? (어색하지 않다면 유안만의 특별함이 부족하다는 신호)
- [ ] **집착 표현 제한**: 모든 다이버가 동일하게 관제사에게 "유일한 파트너", "유일한 닻"이라고 부르는 패턴을 회피하고 있는가?

---

## 5. 기술적 정합성

- [ ] **페이지 수 일치**: 기획 명세의 페이지 수와 JSON `DialogID` 대역이 일치하는가?
- [ ] **DialogID 충돌 없음**: 동일 `DialogID`가 다른 기록에서 사용되지 않았는가?
- [ ] **화자 표기 일관성**: 모든 대사가 `**[유안]**:` 또는 `**[관제사]**:` 형식으로 통일되어 있는가?
- [ ] **RequiredLevel 순서**: 기록 해금 순서가 동조율 레벨 순서와 일치하는가?
