# 침몽도시: 루시드 다이버 - 문서 가이드

> [!IMPORTANT]
> 이 문서는 프로젝트 문서 구조의 최상위 진입점입니다.
> 개발자, 기획자, QA 모두 이 문서를 먼저 읽고 해당 폴더로 이동하세요.

---

## 1. 문서 구조 목적

본 문서 구조는 P0 개발 기준 문서와 기획 참고 문서를 분리하여, 개발자가 최신 구현 범위를 혼동하지 않도록 하기 위한 것이다.

기획 초기부터 누적된 다양한 버전의 명세서, 시나리오, UI 이미지, 스크럼 기록이 혼재해 있어 이를 목적에 따라 명확히 분류한다.

## 3. 개발 기준 문서

> [!IMPORTANT]
> P0 개발 기준은 `01_SSOT_최종_기준문서/` 폴더에 있는 문서만 따른다.

| 파일 | 역할 | 우선순위 |
|---|---|:---:|
| `00_최종_P0_정의서.md` | P0 구현 범위 최종 확정본 | 1순위 |
| `01_P0_시스템_명세서.md` | 각 시스템 동작 규칙 명세 | 2순위 |
| `02_P0_개발자_구현명세서.md` | 씬/매니저/변수/UI 구현 사양 | 3순위 |
| `03_P0_일정표.md` | 주차별 마일스톤 및 일별 계획 | 4순위 |
| `04_P0_QA_체크리스트.md` | 테스트 케이스 및 통과 기준 | 4순위 |

## 4. 문서 충돌 시 우선순위

문서 간 내용이 충돌할 경우 아래 순서를 따른다.

```
1순위: 최종 P0 정의서
2순위: P0 시스템 명세서
3순위: P0 개발자 구현명세서
4순위: P0 일정표 / P0 QA 체크리스트
5순위: 개발 전달용 보조 문서
6순위: 기획 부록 참고 문서
7순위: 아카이브 문서
```

> [!WARNING]
> P0 개발 범위 판단은 반드시 `01_SSOT_최종_기준문서` 폴더의 문서를 기준으로 한다.
> 기획 부록 문서와 P0 시스템 명세가 충돌할 경우, **P0 시스템 명세가 우선**한다.

---

## 5. 부록 문서 사용 규칙

> [!NOTE]
> `03_기획_부록_참고문서/` 폴더의 문서는 세계관, 대사, 심상 기록, 캐릭터 톤, 발표용 설명을 참고하기 위한 자료이다.

**P0 구현 범위가 아닌 항목 (부록 문서에 포함되어 있으나 구현하지 않음):**

- 프롤로그 10단계 튜토리얼
- 대화 선택지
- 3초 탈출 채널링
- 호감도 선물 시스템
- 소대원 모집
- 스킬/패시브/링크 스킬
- 사이드 스토리 2~4
- 각성 일러스트
- 시야 보정 기믹
- 오염도 제한 시간

## 6. 아카이브 문서 사용 규칙

> [!CAUTION]
> `90_Archive_구버전/` 폴더의 문서는 개발 기준으로 사용하지 않는다.
> 히스토리 추적과 과거 기획 확인용으로만 보존한다.

---

## 7. 삭제 후보 문서

> [!NOTE]
> `99_Trash_삭제후보/` 폴더의 문서는 삭제 전 검토가 필요한 중복/불명확 문서이다.
> 프로젝트 완료 전까지 임의 삭제하지 않는다.
> 이동 사유 및 원래 위치는 `99_Trash_삭제후보/삭제후보_목록.md`에서 확인 가능하다.
