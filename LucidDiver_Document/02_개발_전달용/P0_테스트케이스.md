# P0 테스트케이스

> [!NOTE]
> 본 문서는 QA 체크리스트보다 더 구체적인 절차를 기술합니다.
> 개발자(TD)의 자체 테스트 및 PM의 QA 진행 시 이 절차를 따릅니다.

---

## TC-01: 로비 기본 기능 테스트

**전제 조건**: 게임 최초 실행 (SaveData 없음)

**절차:**
1. 게임 실행 → LobbyScene 로드 확인
2. 채린 스탠딩/초상화 이미지 표시 확인
3. 동조율 Lv.0 표시 확인
4. 기본 대사 텍스트 표시 확인
5. [출격] 버튼 클릭 → SortiePreparePanel 진입 확인
6. [뒤로] 클릭 → 로비 메인 복귀 확인
7. [다이버/기록] 버튼 클릭 → DiverRecordPanel 진입 확인
8. 심상 기록 01 잠금 상태 확인 (클릭 불가)
9. [뒤로] → 로비 메인 복귀 확인
10. [창고] 버튼 클릭 → StorageInventoryPanel 진입 확인
11. 마나석/회복약 0개 표시 확인
12. [뒤로] → 로비 메인 복귀 확인

**기대 결과**: 모든 버튼 전환 정상, 초기 데이터 정확

---

## TC-02: 인게임 기본 조작 테스트

**전제 조건**: GameScene 진입 후

**절차:**
1. W 키 → 위쪽 이동 확인
2. A 키 → 왼쪽 이동 확인
3. S 키 → 아래쪽 이동 확인
4. D 키 → 오른쪽 이동 확인
5. 마우스 이동 → 총구 방향 추적 확인
6. 좌클릭 → 탄환 발사 확인
7. 발사 후 playerMana 수치 감소 확인 (HUD 반영)
8. 적 감지 반경 진입 → 적 추적 시작 확인
9. 적 공격 범위 내 → playerHP 감소 확인 (HUD 반영)

**기대 결과**: 조작 반응성 정상, HP/마나 실시간 반영

---

## TC-03: 파밍 테스트

**전제 조건**: GameScene 진입, 아이템 배치 확인 후

**절차:**
1. 기억 파편 오브젝트에 플레이어 충돌 → memoryFragmentCount +1 HUD 확인
2. 마나석 오브젝트에 충돌 → manaStoneCount +1 HUD 확인
3. 회복약 오브젝트에 충돌 → potionCount +1 HUD 확인
4. 여러 개 획득 시 카운터 누적 확인

**기대 결과**: 3종 아이템 모두 충돌 즉시 획득 처리

---

## TC-04: 탈출 성공 → 정산 테스트

**전제 조건**: 기억 파편 1개, 마나석 2개, 회복약 1개 획득 후

**절차:**
1. 전화부스 오브젝트에 접근 → 상호작용 확인
2. ResultPanel 성공 배너 표시 확인
3. 기억 파편 자동 소모 고지 확인 (1개 소모 표시)
4. 동조율 Lv.0 → Lv.1 상승 표시 확인
5. 심상 기록 01 해금 알림 표시 확인
6. 마나석 2개 창고 저장 표시 확인
7. 회복약 1개 창고 저장 표시 확인
8. 성공 귀환 대사 출력 확인
9. [로비로 돌아가기] → LobbyScene 복귀 확인
10. 로비에서 동조율 Lv.1 표시 확인
11. [다이버/기록] 진입 → 기록 01 해금 상태 확인

**기대 결과**: 서사 보상과 파밍 보상이 분리되어 표시, 데이터 정확

---

## TC-05: 실패(HP 0) → 정산 테스트

**전제 조건**: 기억 파편 1개, 마나석 1개, 회복약 1개 획득 후
(창고에 이미 마나석 2개 보관 중 상태)

**절차:**
1. 적에게 피격 반복 → playerHP 0 이하 상태 유도
2. 강제 각성 연출 후 ResultPanel 실패 배너 확인
3. 기억 파편 1개 유실 고지 확인
4. 마나석 1개 유실 고지 확인
5. 회복약 1개 유실 고지 확인
6. 동조율 변화 없음 확인 (Lv.1 유지)
7. 심상 기록 해금 추가 없음 확인
8. [로비로 돌아가기] → LobbyScene 복귀 확인
9. [창고] 진입 → 마나석 여전히 2개 (변동 없음) 확인
10. 회복약 0개 (변동 없음) 확인

**기대 결과**: 실패 시 세션 획득물 전량 유실, 기존 창고 보존

---

## TC-06: 창고 → 슬롯 장착 → 다음 출격 반입 테스트

**전제 조건**: 창고에 마나석 2개, 회복약 1개 보관 중

**절차:**
1. [창고] 진입 → 마나석 2개, 회복약 1개 표시 확인
2. 슬롯 1번에 마나석 장착 (클릭)
3. 슬롯 2번에 회복약 장착 (클릭)
4. [출격 준비] 화면에서 슬롯 1, 2 아이템 아이콘 확인
5. [출격] → GameScene 진입
6. 인게임 퀵슬롯 1에 마나석 아이콘 표시 확인
7. 퀵슬롯 2에 회복약 아이콘 표시 확인

**기대 결과**: 장착 설정이 세션에 반입됨

---

## TC-07: 소모품 인게임 사용 테스트

**전제 조건**: 퀵슬롯 1=마나석, 퀵슬롯 2=회복약 장착 후 세션 진입

**절차:**
1. 마나 일부 소모 (사격)
2. 퀵슬롯 1 사용 키 입력 → playerMana 회복 확인
3. 세션 내 manaStoneCount -1 확인
4. HP 일부 피격 감소
5. 퀵슬롯 2 사용 키 입력 → playerHP 회복 확인
6. 세션 내 potionCount -1 확인

**기대 결과**: 소모품 사용 시 수치 즉시 반영

---

## TC-08: 데이터 영속성 테스트 (저장/불러오기)

**전제 조건**: 성공 탈출 1회 완료 (창고 마나석 2개, 동조율 Lv.1, 기록 해금)

**절차:**
1. 게임 완전 종료
2. 게임 재실행
3. 로비에서 동조율 Lv.1 표시 확인
4. [다이버/기록] → 기록 01 해금 상태 확인
5. [창고] → 마나석 2개 표시 확인

**기대 결과**: 재실행 후에도 모든 영속 데이터 유지

---

## TC-09: P0 종합 루프 테스트 (3회 연속)

**목표**: 치명 오류 없이 3회 연속 완주

1. TC-04 (성공 루트) 실행
2. TC-05 (실패 루트) 실행  
3. TC-06 + TC-04 (창고 장착 후 성공 루트) 실행

**판정**: 3회 모두 오류/크래시 없으면 P0 완료 기준 통과
