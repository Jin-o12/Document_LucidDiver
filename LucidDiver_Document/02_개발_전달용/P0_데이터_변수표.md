# P0 데이터 변수표

> [!IMPORTANT]
> 본 문서는 P0 구현에 필요한 핵심 변수명을 통일하기 위한 공식 참조표입니다.
> 변수명은 이 문서의 정의를 기준으로 모든 코드, 문서, UI에서 일관되게 사용합니다.
> 원본 출처: `01_SSOT_최종_기준문서/02_P0_개발자_구현명세서.md`

---

## 1. SessionLootData (세션 임시 데이터 / 씬 소멸)

세션 진행 중에만 유지되며, 씬 전환 시 결과 정산 후 소멸합니다.

| 변수명 | 타입 | 설명 | 초기값 | 사용 위치 |
|:---|:---:|:---|:---:|:---|
| `memoryFragmentCount` | int | 세션 중 획득한 기억 파편 수 | 0 | 인게임 HUD, ResultPanel |
| `manaStoneCount` | int | 세션 중 획득한 마나석 수 | 0 | 인게임 HUD, ResultPanel |
| `potionCount` | int | 세션 중 획득한 회복약 수 | 0 | 인게임 HUD, ResultPanel |
| `playTime` | float | 세션 플레이 시간 (초) | 0f | ResultPanel |
| `extractionResult` | bool | 탈출 성공 여부 (true=성공) | false | ResultPanel, ResultManager |

---

## 2. PlayerProgressData (영속 저장 / SaveData)

게임 종료 후에도 유지되는 캐릭터 성장 데이터입니다.

| 변수명 | 타입 | 설명 | 초기값 | 사용 위치 |
|:---|:---:|:---|:---:|:---|
| `linkRateLevel` | int | 현재 동조율 단계 | 0 | 로비, ResultPanel, DiverRecordPanel |
| `memoryLogUnlocked` | bool | 심상 기록 01 해금 여부 | false | ResultPanel, DiverRecordPanel |
| `hasNewMemoryLog` | bool | 신규 기록 알림 여부 | false | 로비 메인 NEW 점 |

---

## 3. StorageData (영속 저장 / SaveData)

세션 탈출 성공 시 창고에 누적 저장되는 소모품 수량입니다.

| 변수명 | 타입 | 설명 | 초기값 | 사용 위치 |
|:---|:---:|:---|:---:|:---|
| `storedManaStoneCount` | int | 창고 보관 마나석 총량 | 0 | 창고 패널, 출격 준비 |
| `storedPotionCount` | int | 창고 보관 회복약 총량 | 0 | 창고 패널, 출격 준비 |

---

## 4. QuickSlotData (영속 저장 / SaveData)

다음 출격에 지참할 소모품 슬롯 설정값입니다.

| 변수명 | 타입 | 설명 | 초기값 | 사용 위치 |
|:---|:---:|:---|:---:|:---|
| `equippedItemSlot1` | string | 슬롯 1번 아이템 ID | "" | 창고, 출격 준비, 인게임 퀵슬롯 |
| `equippedItemSlot2` | string | 슬롯 2번 아이템 ID | "" | 창고, 출격 준비, 인게임 퀵슬롯 |

---

## 5. InGamePlayerData (씬 내 실시간 / 저장 불필요)

| 변수명 | 타입 | 설명 | 초기값 |
|:---|:---:|:---|:---:|
| `playerHP` | float | 플레이어 현재 체력 | 설정값 (예: 100) |
| `playerMana` | float | 플레이어 현재 마나 | 설정값 (예: 100) |

---

## 6. DialogueData (대사 제어)

| 변수명 | 타입 | 설명 | 초기값 |
|:---|:---:|:---|:---:|
| `currentDialogueID` | string | 로비 현재 표시 대사 ID | "lobby_default_01" |
| `returnDialogueID` | string | 세션 결과별 귀환 대사 ID | "" |

---

## 7. 아이템 ID 정의

| 아이템 | ID 값 | 설명 |
|:---|:---:|:---|
| 마나석 | `"mana_stone"` | 마나 회복 소모품 |
| 회복약 | `"potion"` | HP 회복 소모품 |
| (기억 파편은 ID 불필요) | - | 카운터로만 관리, 창고 저장 없음 |

---

## 8. 변수명 사용 금지 패턴

> [!WARNING]
> 아래 변수명은 혼동을 방지하기 위해 사용하지 않습니다.

| 금지 표현 | 이유 | 대체 표현 |
|:---|:---|:---|
| `fragmentCount` | 기억 파편인지 불명확 | `memoryFragmentCount` |
| `hp` | 소문자 단일어로 혼동 가능 | `playerHP` |
| `mana` | 단일어로 혼동 가능 | `playerMana` |
| `level` | 무엇의 레벨인지 불명확 | `linkRateLevel` |
| `isUnlocked` | 무엇이 해금인지 불명확 | `memoryLogUnlocked` |
