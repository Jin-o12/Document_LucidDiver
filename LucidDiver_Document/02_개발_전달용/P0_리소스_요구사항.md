# 📋 프로토타입 P0 비주얼 리소스 요구사항 명세서

## 1. 문서 목적

본 사양서는 《침몽도시: 루시드 다이버》 최종 프로토타입 P0 빌드 제작에 필요한 **필수(P0) 비주얼 리소스**만을 발주 및 추적하기 위해 작성되었습니다.

P0 빌드의 목표는 메인 다이버 **채린** 1인을 중심으로 **'PvE 익스트랙션 루프'**와 **'서브컬처 캐릭터 애착 루프'**의 유기적 결합을 검증하는 최소 기능 구현(MVP)입니다.

---

## 2. P0 비주얼 제작 원칙

- **채린 1인 집중**: 플레이어블 캐릭터는 채린 1명만 표시 및 개발합니다.
- **기능 전달 우선**: UI는 완결성 높은 아트 디테일보다 유저가 핵심 루프와 화면 흐름(로비 플로우 명세의 와이어프레임)을 정상적으로 인지할 수 있는 구조를 우선합니다.
- **하이브리드 리소스 수급**: 독창성이 요구되는 핵심 자산(채린 원화, 몽흔, 기억 파편, 결과창 등)은 오리지널로 신규 제작하며, 범용적인 배경, 바닥, 장애물, 적, 공통 VFX 등은 상업적 이용이 가능한 에셋을 적극 가공하여 대체합니다.

## 3. P0 비주얼 리소스 상세 목록

### 3.1 캐릭터 리소스 (로비 / 아웃게임)

> [!NOTE]
> **몽흔(Dreamscar) 리소스 P0 제외 확정**
> `채린 몽흔 최종 시안` 및 `몽흔 아이콘`은 P0 정의서 §5 제외 항목에 따라 이번 프로토타입 빌드에서 구현하지 않습니다.
> 해당 리소스는 P0.5 이후 확장 기획이 확정된 시점에 재검토합니다.

| 리소스명 | 사양 / 설명 | 사용 위치 | 제작 방식 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **채린 스탠딩 일러스트** | 로비에 표시되는 대표 다이버 이미지 (반신 또는 전신 1장). Live2D 적용 또는 단일 정지 스프라이트 중 선택 | 로비 메인, 다이버 상세 | 직접 제작 | **P0 필수** — 아웃게임 캐릭터 핵심 리소스 |

### 3.2 인게임 캐릭터 스프라이트 애니메이션

> [!IMPORTANT]
> 2.5D 아이소메트릭(탑다운) 레벨에 배치되는 플레이어 캐릭터 **채린**의 인게임 스프라이트 시트입니다.
> 방향 기준: **최대 8방향 / 최소 4방향**. 좌우 미러링 활용 시 제작 방향 수를 절반으로 줄일 수 있습니다.
> (예: 우측 4방향만 제작 후 좌측 방향은 Sprite Renderer의 flipX로 처리)

| 리소스명 | 사양 / 설명 | 방향 수 | 우선순위 | 비고 |
| :--- | :--- | :---: | :---: | :--- |
| **채린 Idle 스프라이트** | 정지 대기 상태 루프 애니메이션 | 4방향 ~ 8방향 | **P0 필수** | 미러링 활용 시 4방향(우측) 제작으로 축소 가능 |
| **채린 Walk 스프라이트** | 이동(걷기) 루프 애니메이션. WASD 입력 방향에 따라 재생 | 4방향 ~ 8방향 | **P0 필수** | 이동 입력 벡터 방향과 연동 |
| **채린 Fire 스프라이트** | 사격(공격) 단발 또는 반복 애니메이션. 마우스 조준 방향에 따라 방향 전환 | 4방향 ~ 8방향 | **P0 필수** | 발사 루틴 실행 시 재생 후 Idle/Walk로 복귀 |
| **채린 Run 스프라이트** | 이동(뛰기) 루프 애니메이션. Walk보다 빠른 이동 속도 표현 시 사용 | 4방향 ~ 8방향 | P0.5 선택 | Walk와 시각적 차별점이 없을 경우 생략 가능 |
