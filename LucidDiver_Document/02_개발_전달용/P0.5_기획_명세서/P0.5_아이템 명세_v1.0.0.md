# 기능별 시스템 명세

## 아티팩트란

아티팩트는 인게임 세션 내에서 습득하여 플레이어 캐릭터에 장착하는 특수 장비 아이템이다.

- 기존 `EquipItemData` 테이블의 장비 아이템 구조를 그대로 활용하되, 아티팩트 전용으로 `artifactCategory (enum)` 필드를 추가하여 아이템 분류 시스템을 돕는다.
- 아티팩트는 5개의 등급(노멀 / 언커먼 / 레어 / 에픽 / 레전드)으로 분류되며, 각 등급당 1종이 존재한다.
- 아티팩트는 플레이어 캐릭터의 스탯 및 수치를 조정하는 효과만을 보유하며, 새로운 액션이나 스킬 추가 효과는 갖지 않는다.
- **동일 카테고리의 아티팩트라도 동시에 착용할 수 있다.** P0.5 범위 내 각 카테고리당 1종만 존재하지만, 확장성을 고려하여 카테고리필드는 유지한다. 스탯 중첩 효과에 따른 상한은 캐릭터 명세의 스탯 상한선에 의해 제어된다.

---

## 아티팩트 카테고리 (일람 구분용)

- 각 아티팩트는 하나의 `artifactCategory` 값을 가지며, 이는 아이템 및 효과의 **분류 표시** 목적으로만 사용된다.
    - **동일 카테고리의 아티팩트라도 중첩 착용이 허용된다.**
    - P0.5 단계에서는 각 카테고리당 1종만 존재하므로 실질적 충돌 없음. 향후 동일 카테고리 아이템이 추가될 경우, 스탯 중첩에 따른 밸런스는 캐릭터 명세의 스탯 상한선에 의해 제어된다.

---

## 필드 내 즉시 착용 및 교체

- 플레이어는 인게임 세션 진행 중 아티팩트를 습득한 즉시 장착하거나, 기존 장착 아티팩트와 교체할 수 있다.
    - 로비(아웃게임)에서만 장착 가능한 것이 아닌, 인게임 세션 중 언제든지 인벤토리 UI를 통해 장착 및 교체를 실행할 수 있다.
- 아티팩트 장착 효과(`equipEffectValue`)는 장착 처리가 완료된 즉시 플레이어의 능력치 계산에 반영된다.

---

## 장착 교체 시 기존 아이템 처리

- 장착 중인 아티팩트를 다른 아티팩트로 교체할 경우, 교체된 기존 아티팩트는 플레이어 인벤토리로 자동 반환된다.

### 인벤토리 포화 상태에서의 교체

- 플레이어 인벤토리가 가득 찬 상태에서 필드의 아티팩트를 장착하거나 교체하려는 경우, 인벤토리 UI에서 아이템 간 드래그앤드롭으로 교체를 실행할 수 있다.
    - 드래그앤드롭으로 교체 시, 인벤토리에서 선택한 아이템이 플레이어 현재 위치 바닥에 드롭되고, 새로운 아티팩트가 해당 슬롯을 대체한다.
    - 바닥에 드롭된 아이템은 일정 시간 동안 필드에 잔존하며, 플레이어가 다시 접근하여 재습득하는 것이 가능하다.

---

## 탈출 실패 시 아티팩트 처리

- 탈출 실패(강제 각성 또는 사망) 시, 플레이어가 보유한 아티팩트는 소비 기물 아이템과 동일한 소실 처리 규칙을 따른다.
    - **각성 보존 슬롯에 등록된 아티팩트**: 탈출 실패 시 소실되지 않으며, 세이브 데이터에 그대로 유지된다.
    - **각성 보존 슬롯에 등록되지 않은 아티팩트 (일반 인벤토리 및 장착 슬롯)**: 탈출 실패 시 전부 소실 처리된다.
- 탈출 성공 시에는 장착 중이거나 인벤토리에 보관 중인 아티팩트 전부가 그대로 유지된다.
- 아티팩트 소실 처리는 `ResultManager`의 탈출 실패 정산 코드에서 기존 소비 기물 소실 처리 코드와 동일한 방식으로 구현한다.

## 아티팩트 드롭 규칙

### 드롭 오브젝트 범위

- 아티팩트는 인게임 세션 내 **모든 파밍 가능한 오브젝트**에서 드롭될 수 있다.
    - 파밍 가능한 오브젝트: 아이템 상자, 적 처치 시 드롭, 기타 상호작용 가능한 수납 오브젝트

### 기본 드롭 확률 (일반 구역)

| 오브젝트 종류 | 아티팩트 드롭 여부 판정 확률 |
| --- | --- |
| 아이템 상자 (일반 구역) | 40% |
| 적 처치 드롭 (일반 구역) | 15% |

아티팩트 드롭이 발생하는 경우, 등급별 확률은 이하와 같다.

| 등급 | 드롭 확률 (일반 구역) |
| --- | --- |
| 노멀 | 55% |
| 언커먼 | 25% |
| 레어 | 12% |
| 에픽 | 6% |
| 레전드 | 2% |

### 고위험 구역 드롭 규칙 (마트 건물 내 창고)

- 레벨 디자인 문서에서 지정된 **고위험 구역(마트 건물 내 창고 구역)**의 아이템 상자에서는 아티팩트가 **무조건 1개 이상** 드롭된다.
    - 고위험 구역 아이템 상자에서 드롭 발생 시 등급별 확률은 이하와 같이 일반 구역 대비 고등급 확률이 상향된다.
- 고위험 구역의 적 처치 드롭은 일반 구역과 동일한 드롭 여부 판정(15%) 후, 이하의 고위험 구역 등급 확률 테이블을 사용한다.

| 등급 | 드롭 확률 (고위험 구역) |
| --- | --- |
| 노멀 | 15% |
| 언커먼 | 25% |
| 레어 | 30% |
| 에픽 | 20% |
| 레전드 | 10% |

# 아티팩트 데이터 명세

## EquipItemData 변수 추가

기존 `EquipItemData` 테이블에 이하의 변수를 추가하여 아티팩트 카테고리를 정의한다.

| 변수명 | 변수 자료형 | 변수 설명 |
| --- | --- | --- |
| artifactCategory | ArtifactCategory (enum) | 아티팩트의 카테고리 분류. 이름 표시 및 아이템 구분 목적으로 사용됨. 중첩 착용 허용 |

## ArtifactCategory Enum 정의

```csharp
public enum ArtifactCategory
{
    None,         // 아티팩트 카테고리 미사용 (일반 장비 호환용)
    HP_Related,   // HP 재생 관련 효과를 보유한 아티팩트
    MP_Related,   // MP 재생 관련 효과를 보유한 아티팩트
    Mobility,     // 이동 속도 관련 효과를 보유한 아티팩트
    TimeLimit,    // 세션 시간 제한 관련 효과를 보유한 아티팩트
    Combat,       // 공격 속도 및 공격 효율 관련 효과를 보유한 아티팩트
}
```

- 향후 새로운 효과 계열의 아티팩트 추가 시 `ArtifactCategory`에 원소를 추가하여 확장한다.
- 일반 장비 아이템(아티팩트가 아닌 EquipItem)은 `None`으로 설정하여 카테고리 로직에서 제외한다.
- **동일 카테고리라도 중첩 착용 허용.** P0.5 이후 동일 카테고리 내 신규 아이템이 추가될 경우 동일 카테고리 내 수치가 중첩되며, 스탯 상한선은 캐릭터 명세에서 제어한다.

| useChanneling | bool | 채널링 중 피격 시 취소 여부 |
| useCooltime | float | 효과 적용 후 쿨타임 (초). 쿨타임 없음 시 0.0 |
