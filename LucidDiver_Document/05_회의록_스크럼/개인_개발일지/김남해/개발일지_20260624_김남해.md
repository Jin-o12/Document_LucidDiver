### 3. Scroll View Viewport 렌더링 이슈 분석 및 해결
- **내용**:
  - `Scroll View-RecordList > Viewport`에 Mask를 켜면 RecordCard가 무조건 보이지 않는 현상이 발생했습니다.
  - **원인 분석**: Unity의 Mask 스텐실 클리핑이 Viewport의 RectTransform 기준과 실제 렌더링 좌표 간의 불일치로 꼬인 상태로 판단.
  - **해결 방법**: Mask 컴포넌트를 제거하고 **Rect Mask 2D**로 교체.
    - Rect Mask 2D는 스텐실 방식 대신 RectTransform 사각형 기준으로 자식 UI를 단순 클리핑하여 Scroll View에서 더 안정적으로 동작.
  - **최종 Viewport 컴포넌트 구성**:
    - `RectTransform` (Anchor: Stretch/Stretch, Left: 0, Right: 25, Top: 0, Bottom: 0)
    - `Image` (Color: White, Alpha: 0, Raycast Target: On)
    - `Rect Mask 2D`
    - ~~`Mask`~~ (제거)
  - **Content-RecordList 최종 설정**:
    - Anchor Preset: Top Stretch
    - Pos Y: 0 / Pivot Y: 1
    - Height: 505 (카드 2개 기준: 250 + 5 + 250 = 505)
    - Vertical Layout Group: Spacing 5, Child Force Expand Height: Off
    - Content Size Fitter: Vertical Fit: Preferred Size
- **결과**: Play 상태에서 RecordCard 정상 표시 확인. Scroll 동작도 정상.

## 🛠️ 트러블슈팅

### Scroll View RecordCard가 Mask 적용 시 보이지 않는 문제
- **증상**: Viewport에 Mask 컴포넌트를 켜면 RecordCard가 완전히 비표시됨.
- **원인**: Unity Mask의 스텐실 클리핑 방식이 Viewport RectTransform과 실제 렌더링 좌표 불일치로 꼬인 상태. 또는 Scroll View 기본 구조 초기화 오류.
- **해결**: Viewport에서 Mask 컴포넌트 제거 → **Rect Mask 2D 추가**로 교체. Rect Mask 2D는 스텐실 없이 RectTransform 사각형 기준으로 단순 클리핑하여 Scroll View에서 훨씬 안정적으로 동작.
- **결과**: Play 상태에서 RecordCard 정상 표시 확인.
