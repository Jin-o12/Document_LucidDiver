## ✅ 완료한 작업

### 1. 상호작용 이미지 활성화 시 총기 발사 차단 문제 해결

- **내용**: 문이나 아이템 상자에 접근해 상호작용 가이드 이미지가 활성화된 상태에서 마우스 좌클릭 입력(총기 발사)이 먹통이 되는 현상을 수정했다.
- **원인**: 상호작용 UI 이미지의 `Raycast Target` 옵션이 켜져 있어 마우스 좌클릭 클릭 이벤트를 UI가 가로막아(Raycast Block) 게임월드의 사격 입력으로 전달되지 않는 문제였다.
- **구현 사항**:
  - 문(Door)과 아이템 상자(Item Box)에 배치된 UI 오브젝트의 이미지 컴포넌트를 확인했다.
  - 마우스 클릭 상호작용이 불필요한 가이드 이미지들의 `Raycast Target` 옵션을 일괄 **비활성화**했다.
- **결과**: 상호작용 가이드 UI가 화면에 띄워진 상태에서도 사격 입력(마우스 좌클릭)이 정상적으로 작동하여 자연스러운 전투 연출이 가능해졌다.

---

### 2. 카메라 설정 변경 (Perspective → Orthographic)

- **내용**: 탑다운 쿼터뷰 시점의 일관된 공간 투영과 왜곡 없는 화면 연출을 위해 카메라 설정을 조정했다.
- **구현 사항**:
  - Main Camera의 Projection 설정을 `Perspective`에서 **`Orthographic`**으로 변경했다.
  - 쿼터뷰(Quarter View) 구도 정렬을 위해 카메라의 Rotation 값을 **X:45, Y:45, Z:0**으로 수정했다.
- **결과**: 화면 중심과 가장자리 간의 원근 왜곡이 사라져 레벨디자인 요소들이 보다 안정감 있고 균일한 크기로 시각화된다.

---

### 3. 발표자료 작성 집중

- **내용**: 진행 중인 프로젝트의 최종 성과를 공유하기 위한 공식 발표자료 작성에 집중했다.
- **결과**: 템플릿의 초안이 작성되었고 내일 수정과 보완을 통해 완성 예정이다.

## 🛠️ 트러블슈팅

### 1. 상호작용 UI가 활성화되면 총기 발사(마우스 클릭)가 작동하지 않는 문제

1. **문제 상황**: 문이나 상자 근처에서 상호작용 가이드 이미지가 표시된 상태에서 마우스 좌클릭을 해도 총이 발사되지 않는 현상이 발생했다.
2. **발생 조건**: 상호작용 트리거에 진입하여 가이드 이미지(Canvas UI)가 활성화되어 있을 때 발생했다.
3. **원인**: UI 이미지 컴포넌트의 `Raycast Target`이 켜져 있어, 마우스 좌클릭 시 Event System이 클릭을 UI에서 소비하고 씬 내 총기 발사 입력으로 전달하지 못했다.
4. **해결**: 문과 상자 UI 내 가이드 이미지 오브젝트의 `Raycast Target` 설정을 비활성화했다.
5. **결과**: 가이드 UI의 활성화 상태와 무관하게 정상적으로 좌클릭 사격을 할 수 있게 되었다.
