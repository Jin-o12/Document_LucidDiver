## 🔄 진행 중인 작업

### 1. 방 내부용 소품 에셋 조사 (신규)
- **배경**: 마켓 내부에 벽으로 분리된 **부속실(직원실, 창고 사무 공간 등)**이 존재하나, 현재 사용 중인 `Modular Retail Environment` 에셋에는 해당 공간에 어울리는 **실내 소품이 부재**한 상태이다.
- **필요 소품 목록**:

  | 소품 | 용도 | 우선순위 |
  |:---|:---|:---:|
  | 책상 (Desk) | 직원실·사무 공간 연출 | ★★★ |
  | 의자 (Chair) | 직원실·휴게실 연출 | ★★★ |
  | 사물함 (Locker) | 직원 탈의실·창고 연출 | ★★★ |
  | TV / 모니터 | 보안 모니터링 구역, 직원실 | ★★☆ |
  | 선반·랙 (Rack/Shelf, 창고용) | 창고 내 물품 적재 연출 | ★★☆ |
  | 소파·벤치 | 휴게실 연출 | ★☆☆ |

- **다음 단계**: Unity Asset Store 및 Fab.com에서 위 소품을 포함한 에셋 팩 조사. 기존 에셋과 비주얼 톤 매칭 가능 여부 우선 확인.
- **진행 상태**: 🔍 에셋 조사 예정

## 🛠️ 트러블슈팅

### 1. 내부 방 구획 시 벽체 정렬 오차
- **증상**: 내부 파티션 벽 배치 시, 그리드 스냅이 외벽 기준과 미세하게 어긋나 틈새(Gap)가 발생.
- **원인**: `Modular Retail Environment` 내부 파티션 프리팹의 pivot이 끝점(edge) 기준이라 외벽(center 기준)과 스냅 시 오프셋 발생.
- **해결**: Unity의 **Vertex Snap(V키)** 기능으로 꼭짓점 기준 수동 정렬. 이후 Grid Unit(1m) 기준으로 배치 통일.
