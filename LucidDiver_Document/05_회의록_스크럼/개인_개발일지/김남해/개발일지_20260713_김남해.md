## ✅ 완료한 작업

### 1. FlatKit 에셋 맵 전체 적용 — Renderer Feature 방식 채택

FlatKit 에셋은 두 가지 적용 방식을 지원한다.

| 적용 방식 | 설명 | 채택 여부 |
|:---|:---|:---:|
| **개별 머티리얼 적용** | 오브젝트마다 FlatKit 머티리얼을 직접 교체 | ❌ |
| **Renderer Feature 전체 적용** | URP의 Renderer Feature로 씬 전체에 일괄 적용 | ✅ |

개별 머티리얼 교체 방식은 오브젝트 수가 많은 현재 맵 구조에서 작업량이 과도하게 늘어나는 단점이 있다. 따라서 **Renderer Feature 방식으로 맵 전체에 일괄 적용**하는 방향을 채택하였다.

#### 작업 내용
- URP의 `Universal Renderer Data` 에셋에 FlatKit Renderer Feature 추가
- FlatKit Stylized Surface 및 Outline 설정 구성
- 전체 씬에 적용 확인

### 2. FlatKit Renderer Feature 적용 후 캐릭터 렌더링 이슈 발생 및 원인 분석

Renderer Feature를 전체 적용한 결과, AniPortrait로 제작된 플레이어 및 에너미 캐릭터에서 두 가지 렌더링 이슈가 확인되었다.

#### 발생 이슈

| # | 현상 | 원인 |
|:---:|:---|:---|
| 1 | **캐릭터 파츠별 개별 Outline** | AniPortrait 캐릭터는 몸통·팔·다리 등 복수의 파츠 메시로 구성되어 있어, Outline Renderer Feature가 각 파츠를 독립된 오브젝트로 인식하고 개별 외곽선을 그림 |
| 2 | **조명이 있는 영역에서 캐릭터 투명화 및 뒤 오브젝트 비침** | FlatKit의 Stylized Surface 렌더링 로직이 AniPortrait 캐릭터 쉐이더와 충돌하여 알파·조명 처리 오작동 |

#### 영향 범위
- 플레이어 캐릭터, 에너미 캐릭터 전체
- 조명이 배치된 실내 구역에서 시각적 파탄 수준의 그래픽 깨짐 발생

---

### 3. Universal Renderer Data 분리 및 Culling Mask 적용으로 문제 해결

FlatKit의 Renderer Feature를 환경 오브젝트에만 한정 적용하고, 캐릭터는 별도 렌더러로 처리하는 구조로 분리하여 문제를 해결하였다.

#### 해결 구조

```
[Camera - Environment]          [Camera - Character]
 └─ Universal Renderer Data      └─ Universal Renderer Data
    (환경 전용)                      (캐릭터 전용)
    ├─ FlatKit Pixcelation       └─ 기본 URP 렌더러
    └─ FlatKit Outline                  (FlatKit 미적용)
    └─ FlatKit Fog
 └─ Culling Mask: Environment    └─ Culling Mask: Character
```

#### 작업 내용
1. **Renderer Data 분리**
   - 기존 `Universal Renderer Data` → `RendererData_Environment` (FlatKit Feature 포함)
   - 신규 `RendererData_Character` 생성 (FlatKit Feature 미포함, 기본 URP)

2. **레이어 분리**
   - Unity Layer에 `Player`, `Enemy` 레이어 분리 적용
   - 씬 내 모든 환경 오브젝트 → 캐릭터 제외한 레이어 배정
   - 플레이어 및 에너미 캐릭터 오브젝트 → `Player`, `Enemy` 레이어 배정

3. **카메라 Culling Mask 설정**
   - 환경용 카메라: Culling Mask = 캐릭터 제외한 레이어만 렌더링
   - 캐릭터용 카메라: Culling Mask = `Player`, `Enemy` 레이어만 렌더링
   - 두 카메라의 출력 결과를 합성하여 최종 화면 구성

#### 결과
- 캐릭터 파츠별 개별 Outline 이슈 해소 ✅
- 캐릭터 투명화 이슈 해소 ✅
- 환경 오브젝트에는 FlatKit 스타일이 정상 적용됨 ✅
- 캐릭터는 기존 쉐이더로 정상 렌더링됨 ✅

## 🛠️ 트러블슈팅

### FlatKit Renderer Feature — 캐릭터 파츠 개별 Outline 및 투명화 이슈

- **현상 1**: AniPortrait 캐릭터의 각 메시 파츠마다 Outline이 개별 적용되어 부자연스러운 외곽선 형성
- **현상 2**: 조명이 있는 구역에서 캐릭터가 반투명해지고 뒤 오브젝트가 비쳐 보임
- **원인**: FlatKit Renderer Feature가 씬 전체 오브젝트에 일괄 적용되면서, AniPortrait 캐릭터의 복합 메시 구조 및 전용 쉐이더와 충돌 발생
- **해결**: `Universal Renderer Data`를 환경용/캐릭터용으로 분리 생성 → Unity 레이어로 환경/캐릭터 구분 → 카메라 Culling Mask로 각 렌더러가 담당 레이어만 처리하도록 구성 → 렌더러 간 간섭 원천 차단
