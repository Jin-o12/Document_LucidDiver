## 💡 개발 비전 (Vision)

FlatKit 적용과 벽 투명 처리 기능을 유지하면서, Player 레이어에 있는 플레이어 캐릭터의 그림자가 맵 바닥에 정상적으로 표시되도록 렌더링 구조를 개선한다. Base Camera / Overlay Camera 이중 구조에서 그림자 정보가 올바르게 전달되도록 레이어·카메라·광원 설정을 분리하고, AniPortrait 2D 평면 메시의 그림자 한계를 인식하여 다음 단계 해결 방향을 설계한다.

## ✅ 완료한 작업

### 1. 원인 분석 — Base Camera의 Culling Mask와 Shadow Map의 관계

현재 렌더링 구조는 다음과 같다.

| 카메라 | 역할 | 렌더링 대상 |
|:---|:---|:---|
| Main Camera (Base Camera) | 맵, 환경 오브젝트 렌더링 | Player·Enemy 레이어 제외 |
| Character Camera (Overlay Camera) | 캐릭터 렌더링 | Player·Enemy 레이어만, FlatKit Character Renderer 사용, Clear Depth 활성화 |

플레이어 캐릭터는 AniPortrait로 제작된 2D 메시 캐릭터다.

**그림자가 사라지는 근본 원인:**

```
플레이어가 Default 레이어인 경우
  → Base 카메라가 플레이어 렌더러를 인식
  → 플레이어가 Shadow Map에 포함됨
  → 바닥에 그림자 표시 ✅

플레이어가 Player 레이어인 경우
  → Base 카메라의 Culling Mask에서 Player 레이어가 제외됨
  → Shadow Map에 플레이어가 포함되지 않음
  → 바닥에 그림자가 표시되지 않음 ❌
```

Overlay 카메라는 플레이어를 렌더링하지만, 그림자를 받는 **바닥은 Base 카메라**에서 렌더링된다. 따라서 Overlay 카메라만으로는 바닥 그림자를 만들 수 없다.

---

### 2. 해결 설계 — PlayerShadow 전용 레이어 분리

플레이어 AniPortrait 오브젝트를 복제하여 그림자 생성만 담당하는 전용 오브젝트를 분리하는 구조를 적용했다.

#### 오브젝트 구성

```
Player_Yuan
└─ Body
   ├─ Yuan (Optimized) 1
   │  - Layer: Player
   │  - Mesh Shadow Casting Mode: Off
   │  - 실제 캐릭터 렌더링 담당
   │
   └─ Yuan (Optimized) 1 Shadow
      - Layer: PlayerShadow
      - Mesh Shadow Casting Mode: Shadows Only
      - Mesh Receive Shadow: Off
      - 그림자 생성 전담
```

#### 카메라 Culling Mask 설정

| 카메라 | Player 레이어 | PlayerShadow 레이어 |
|:---|:---:|:---:|
| Main Camera (Base) | ❌ 제외 | ✅ 포함 |
| Character Camera (Overlay) | ✅ 포함 | ❌ 제외 |

이 구성으로 Base 카메라가 PlayerShadow를 인식하여 Shadow Map에 포함시키고, 바닥에 그림자가 투영된다.

---

### 3. 2차 문제 해결 — Directional Light Shadows 비활성화

그림자 전용 복제본 구성 이후에도 바닥 그림자가 표시되지 않는 문제가 발생했다.

원인 후보를 순차적으로 점검하던 중 **Directional Light의 Shadows 옵션이 `None`으로 설정**되어 있던 것을 확인했다.

| 설정 항목 | 수정 전 | 수정 후 |
|:---|:---:|:---:|
| Directional Light → Shadows | None | Soft Shadows |

수정 이후 PlayerShadow 레이어의 그림자 전용 캐릭터가 바닥에 그림자를 정상적으로 생성하기 시작했다.

---

### 4. 3차 문제 해결 — AnimatorShadowSync 스크립트 작성

그림자는 나타났지만, 플레이어가 이동하거나 공격해도 그림자 캐릭터는 Idle 자세로 고정되는 문제가 발생했다.

#### 원인

원본 캐릭터와 그림자 복제본은 각각 별도의 `Animator` 컴포넌트를 가지고 있다. 같은 Animator Controller를 공유하더라도 원본 Animator에 전달되는 이동·공격 파라미터가 그림자 Animator에 자동으로 반영되지 않는다.

```
원본 Animator    → 이동·공격 파라미터 갱신 → 실제 캐릭터 애니메이션 재생 ✅
그림자 Animator  → 파라미터가 초기값 유지  → Idle 애니메이션만 재생 ❌
```

#### 해결 — AnimatorShadowSync

원본 Animator의 상태를 그림자 Animator에 매 프레임 동기화하는 스크립트를 추가했다.

**동기화 대상:**

| 항목 | 내용 |
|:---|:---|
| Float 파라미터 | 이동 속도 등 |
| Int 파라미터 | 상태 열거값 등 |
| Bool 파라미터 | 공격 여부 등 |
| Layer Weight | 레이어별 가중치 |
| Speed | Animator 재생 속도 |
| UpdateMode | Animator Update Mode |

**추가 설정:**

```
그림자 Animator
└─ Culling Mode: Always Animate
```

화면 밖에서도 그림자 애니메이션이 정지되지 않도록 `Always Animate`로 설정했다.

#### 결과

플레이어의 이동 및 애니메이션과 그림자 복제본의 자세가 정상적으로 동기화됐다.

## 🔄 진행 중인 작업

### AniPortrait 2D 평면 메시 그림자 부자연스러움

애니메이션 동기화 이후에도 그림자가 일반적인 3D 캐릭터 그림자처럼 보이지 않는 문제가 남아 있다.

#### 원인

AniPortrait 캐릭터는 입체적인 3D 메시가 아니라 카메라를 향하는 **얇은 2D 평면 메시**다. Directional Light는 이 평면 메시의 알파 실루엣을 그대로 바닥에 투영하므로, 캐릭터 이미지 형태가 납작하게 바닥에 찍힌다.

```
3D 캐릭터
  → 신체 부위마다 깊이 정보 존재
  → 광원 방향에 따른 입체적인 그림자 생성 ✅

AniPortrait 캐릭터
  → 깊이가 거의 없는 평면 메시
  → 캐릭터 이미지 형태가 그대로 바닥에 투영 ❌
```

#### 다음 단계 검토 방향

**Option A — Blob Shadow**

플레이어 발밑에 반투명 타원형 스프라이트를 배치하는 방식. 구현이 단순하고 성능 부담이 적지만, 광원 방향 변화에 반응하지 않는다.

## 🛠️ 트러블슈팅

### 1. Player 레이어 변경 후 그림자 소실

- **현상**: 플레이어 레이어를 Default → Player로 변경하자 바닥 그림자가 사라짐
- **원인**: Base 카메라의 Culling Mask에서 Player 레이어가 제외되어 있어 Shadow Map에 플레이어가 포함되지 않음
- **해결**: PlayerShadow 전용 레이어를 생성하고, 그림자 전용 복제본을 Base 카메라에만 포함시켜 Shadow Map에 반영

### 2. 그림자 복제본 설정 후에도 그림자 미표시

- **현상**: PlayerShadow 레이어 복제본을 구성했음에도 바닥에 그림자가 생성되지 않음
- **원인**: Directional Light의 `Shadows` 옵션이 `None`으로 비활성화되어 있었음
- **시도한 점검 항목**: Shadow Casting Mode 설정 / 레이어 적용 범위 / Overlay 카메라 렌더링 여부 / FlatKit Renderer Feature 중복 렌더링 여부 / 광원 설정
- **해결**: Directional Light → Shadows를 `Hard Shadows` 또는 `Soft Shadows`로 변경

### 3. 그림자 Animator가 Idle 자세에 고정됨

- **현상**: 플레이어가 이동·공격해도 그림자 복제본은 Idle 자세로 고정됨
- **원인**: 원본과 그림자 복제본이 각각 독립적인 Animator를 가지며, 파라미터가 자동 공유되지 않음
- **해결**: `AnimatorShadowSync` 스크립트로 Float·Int·Bool 파라미터, Layer Weight, Speed, UpdateMode를 매 프레임 동기화. 그림자 Animator의 Culling Mode를 `Always Animate`로 설정
