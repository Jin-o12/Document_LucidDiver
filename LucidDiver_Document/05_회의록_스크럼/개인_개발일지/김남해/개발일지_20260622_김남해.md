## ✅ 완료한 작업

### 1. 3차 프로젝트 유료 에셋 사전기획서 작성
- **내용**:
  - 2주차 개발 킥오프에 앞서, 향후 3차 프로젝트 진행 시 필요한 유료 에셋에 대한 **사전기획서**를 작성했습니다.
  - 유료 에셋으로 대체 시 얻을 수 있는 이점, 도입 사유를 기술·아트 관점에서 구체적으로 서술했습니다.
  - 엘리스 측에서 제시한 양식에 맞춰 작성했습니다.
- **의사결정**:
  - 3차 프로젝트 일정(에셋 적용 3주차 예정)과의 연계를 고려해 도입 우선순위 순서로 정렬했습니다.
- **결과**: 유료 에셋 도입 사유 및 후보 목록이 포함된 사전기획서 초안 완성. CP(장수영) 검토 요청 예정.
- **관련 파일**: 유료 에셋 사전기획서 (별도 파일)

---

### 2. LobbyScene UI 제작
- **내용**:
  - Unity LobbyScene에 로비 메인 패널 UI를 제작했습니다.
  - **Canvas_Lobby > LobbyMainPanel** 하위에 다음 그룹 단위로 구성했습니다:
    - **`BackgroundGroup`**: 배경 이미지 레이어
    - **`DiverStandingGroup`**: 캐릭터 일러스트 전신 이미지 배치
    - **`RightMenuGroup`**: 우측 메뉴 버튼 3종 (출격 / 다이버 / 창고)
    - **`CenterDiverInfoGroup`**: 다이버 정보 패널 (이름, 역할, 동조율 게이지, 링크 상태 등)
    - **`BottomDialogueGroup`**: 하단 캐릭터 대화 창
    - **`TopBarGroup`**: 상단 타이틀 및 씬 명칭 배너 (관제실 / CONTROL ROOM)
  - 해상도: 2400×1080 Aspect 기준으로 레이아웃 설계.
- **의사결정**:
  - 2주차 방침('기능 구현 우선, 비주얼 수정은 3주차')에 따라 UI 프리팹 구조를 잡아 3주차 에셋 교체 및 디자인 수정이 용이하도록 구성했습니다.
  - `CenterDiverInfoGroup` 내 동조율 게이지 및 상태 텍스트는 데이터 변수와 연동될 수 있도록 TMP 컴포넌트 구조로 분리했습니다.
- **결과**: LobbyScene 메인 패널 UI 1차 시안 구현 완료. Scene/Game View 모두 정상 렌더링 확인.
- **관련 파일**:
  - Unity LobbyScene (Assets/01_Scenes/LobbyScene)
  - Canvas_Lobby 프리팹 구조
