## ✅ 완료한 작업

### 1. Modular Retail Environment 콜라이더 누락 — 에셋 제작사 디스코드 문의
- **내용**:
  - 전일(2026-06-25) 확인된 유료 에셋 **Modular Retail Environment**의 콜라이더 누락 문제에 대한 후속 조치로, 에셋 제작사 공식 디스코드 채널에 문의를 남겼다.
  - 문의 내용: 현재 구매한 에셋 패키지에 콜라이더가 포함되지 않은 점을 확인했으며, 콜라이더가 포함된 버전의 에셋을 별도로 제공받을 수 있는지 확인 요청.
- **의사결정**:
  - 수동으로 콜라이더를 추가하는 방식보다 제작사로부터 공식 지원을 받는 것이 유지보수 측면에서 유리하다고 판단하여 문의를 우선 진행했다.
  - 답신 내용에 따라 수동 추가 또는 대체 에셋 검토 등 후속 방향을 결정할 예정이다.
- **결과**: 디스코드 문의 완료. 아직 답신이 오지 않은 상태.

---

## 🔄 진행 중인 작업

### 1. 로비씬 UI SetActive 구조 → UIManager 기반 구조 전환 (미완료)
- **내용**:
  - 기존 로비씬의 UI 패널들은 각각의 버튼 OnClick()에 직접 연결되어 `SetActive`로 표시/숨김을 처리하는 구조였다.
  - 프로젝트 전체와의 통합성을 높이기 위해 `UIManager`가 각 패널을 중앙에서 관리하는 구조로 전환을 시도했다.
- **진행 상황**: 구조 전환 작업을 시도하였으나 목표를 달성하지 못한 채 작업이 중단되었다.
- **미완료 원인**: `Utils` 폴더의 `GlobalEventBus.cs` 스크립트 내에 UI 패널을 여는 함수가 이미 구현되어 있다는 사실을 인지하지 못한 상태에서 작업을 진행했다. 별도의 스크립트를 생성하거나 기존 `GlobalEventBus`의 함수를 활용하는 방향을 검토하지 않고, UI 패널들을 각각 직접 연결하는 방식만 시도하다 막혔다.

## 🛠️ 트러블슈팅

### 로비씬 UI → UIManager 전환 실패 (GlobalEventBus 미파악)
- **증상**: UIManager 기반 구조로 전환하려 했으나 패널 전환이 정상 동작하지 않았고, 작업이 진전되지 않았다.
- **원인**: `Utils/GlobalEventBus.cs` 내에 UI 패널을 여는 전용 함수가 이미 구현되어 있다는 사실을 인지하지 못한 채 작업을 시작했다. 기존 이벤트 버스를 활용하지 않고 패널들을 각각 직접 연결하는 방식만 반복 시도하여 구조적 해결에 이르지 못했다.
- **해결**: `Utils/GlobalEventBus.cs`에 이미 구현된 UI 패널 열기 함수의 사용 방식을 먼저 파악한 후, 이를 활용하거나 필요한 경우 래핑 스크립트를 추가 작성하는 방향으로 내일 재시도할 예정.
