## ✅ 완료한 작업

### 1. 추가 소품 에셋 선별 및 임포트

전일 조사 계획에 따라 Unity Asset Store에서 아래 3종 에셋을 임포트하였다.

| 에셋명 | 주요 소품 | 라이선스 |
|:---|:---|:---:|
| **Industrial Cabinets and Shelves Lite** | 산업용 캐비닛, 창고용 선반·랙 | 무료 |
| **Low-Poly Office Set #1 [+140 Models] [VNB]** | 책상, 의자, 사물함, 모니터, 사무기기 등 140여 종 | 무료 |
| **Stylized Vehicles Pack - FREE** | 승용차, 밴, 트럭 등 스타일라이즈드 차량 | 무료 |

> **선정 이유**:
> - `Industrial Cabinets and Shelves Lite` — 창고·백룸 구역에 어울리는 금속 선반·캐비닛 제공. 기존 `Modular Retail Environment` 의 산업적 톤과 매칭.
> - `Low-Poly Office Set #1` — 직원실·사무 공간에 필요한 소품 140여 종이 단일 팩에 포함. Low-poly 스타일이 게임 전반의 비주얼 방향과 일치.
> - `Stylized Vehicles Pack - FREE` — 슈퍼숍 외부 주차 구역 연출용. 적 배회 구역에 엄폐물 역할 겸 환경 밀도 향상.

---

### 2. URP 호환성 검사

임포트 후 각 에셋의 셰이더 호환 여부를 점검하였다.

| 에셋명 | 임포트 시 셰이더 상태 | 조치 |
|:---|:---|:---|
| **Industrial Cabinets and Shelves Lite** | Built-in `Standard` 셰이더 사용 → 핑크 머티리얼 다수 | URP/Lit 수동 변환 |
| **Low-Poly Office Set #1** | Built-in `Standard` 셰이더 사용 → 핑크 머티리얼 다수 | URP/Lit 수동 변환 |
| **Stylized Vehicles Pack - FREE** | 일부 머티리얼 Built-in 혼용 | 해당 머티리얼만 선별 변환 |

> ✅ `Edit > Rendering > Render Pipeline Converter`(URP Upgrade 유틸리티) 자동 변환 적용 후, 텍스처가 누락되거나 의도와 다른 머티리얼은 수동 교체.

---

### 3. 머티리얼 수정

자동 변환 후 육안 검사를 통해 아래 항목을 수동 수정하였다.

- **Industrial Cabinets and Shelves Lite**
  - 금속 선반 머티리얼: `Metallic` 값 0.7 → 0.85, `Smoothness` 0.4 → 0.3 조정 (광택 과다 억제)
  - 캐비닛 도어 머티리얼: `Base Color` 채도 낮춰 창고 환경 톤 맞춤

- **Low-Poly Office Set #1**
  - 의자·소파 패브릭 머티리얼: 자동 변환 후 `Normal Map` 누락 → 원본 텍스처 수동 재연결
  - 모니터 스크린 머티리얼: `Emission` 활성화하여 켜진 화면 연출 추가

- **Stylized Vehicles Pack - FREE**
  - 차량 바디 머티리얼: 컬러 팔레트 기존 씬 환경(외부 도로, 인도 색조)과 맞춰 `Base Color` 미세 조정
  - 창문 유리 머티리얼: `Surface Type` → Transparent, `Alpha` 0.45 설정

## 🛠️ 트러블슈팅

### 1. URP 자동 변환 후 핑크 머티리얼 다수 발생
- **증상**: `Render Pipeline Converter` 자동 변환 후 `Industrial Cabinets and Shelves Lite` 및 `Low-Poly Office Set #1` 다수 머티리얼이 핑크(셰이더 오류) 상태.
- **원인**: 자동 변환 도구가 일부 커스텀 셰이더 또는 멀티 서브메시 구조를 지원하지 못하여 셰이더 참조가 끊김.
- **해결**: 해당 머티리얼 선택 → Inspector에서 Shader를 `Universal Render Pipeline/Lit`으로 수동 변경 후 Albedo/Normal/Metallic 텍스처 재연결.

### 2. 차량 배치 시 지면 관통 현상
- **증상**: `Stylized Vehicles Pack` 차량 일부가 지면 메시와 교차하여 바퀴가 지면 아래로 꺼지는 현상.
- **원인**: 차량 프리팹의 pivot이 메시 최하단이 아닌 기하 중심부에 설정되어 있어, Y축 위치 맞춤 시 오프셋 발생.
- **해결**: 각 차량 프리팹의 Y 위치값을 수동 조정 (지면 Y=0 기준, 차량별 오프셋 값 메모 보관).
