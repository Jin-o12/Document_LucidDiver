## ✅ 완료한 작업

### 1. 아이템 데이터 관리 방식 변경 (JSON 전환)
- **내용**: 
  - 기존 Scriptable Object(SO)로 개별 관리하던 아이템 데이터를 Excel 파일로 통합 관리하고, 이를 JSON 형식으로 변환하여 게임 내에서 파싱하는 방식으로 데이터 구조를 전면 개편했습니다.
- **결과**: 데이터의 접근성 및 확장성을 확보하였으며, 기획 파트의 대규모 아이템 밸런싱 수정 및 반영 속도를 대폭 개선할 수 있는 기반을 마련했습니다.

### 2. Addressable Asset 유틸리티 추가 및 내부 구조 개선
- **내용**:
  - Addressable 시스템을 통해 리소스 파일을 안정적으로 호출할 수 있도록 돕는 전용 유틸리티 스크립트 `AddressableLoader`를 신규 추가했습니다.
  - 해당 유틸리티를 적용하여 아이템 아이콘을 동적으로 로드하는 기존 스크립트들의 의존성을 낮추고, 코드 재사용성을 높이기 위한 리팩토링 작업을 완수했습니다.
- **결과**: 리소스 로딩 과정을 일원화하여 메모리 관리 효율성을 높였으며, 향후 다양한 에셋(스킬 아이콘 등) 추가 시 유연한 대처가 가능해졌습니다.
