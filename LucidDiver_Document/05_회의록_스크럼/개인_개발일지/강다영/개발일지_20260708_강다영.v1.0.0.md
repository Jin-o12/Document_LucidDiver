## ✅ 완료한 작업

### 1. 스킬 사용 시 부가 기능 및 데이터 연동 추가
- **내용**: 
  - 스킬 사용 효과를 다양화하기 위해 `EffectType` 열거형에 신규 항목을 추가했습니다.
  - 스킬 사용 시 플레이어의 스탯 정보를 전달할 수 있도록 `CasterStatPayload` 구조체를 생성했습니다.
  - 마나 소모 로직을 추가하고, 현재 마나 잔여량에 따라 스킬 시전 가능 여부를 판별하는 기능을 구현했습니다.
- **결과**: 스킬 시스템 내 데이터 전달 체계를 확장하고 마나 코스트 기반의 스킬 사용 조건을 마련했습니다.

### 2. 스킬 사용 시 제한 요소 및 예외 처리 도입
- **내용**: 
  - 스킬 시전 조건(마나 부족 등)을 만족하지 못해 스킬이 발동되지 않을 경우, 플레이어의 스킬 사용 애니메이션도 출력되지 않도록 제약을 추가했습니다.
  - 스킬이 지정된 최대 사거리 밖으로 발사되지 않도록 범위를 제한했습니다.
  - 스킬의 시전 속도를 제어하고 쿨타임을 적용하여, 지정된 주기로만 스킬을 사용할 수 있도록 밸런스 기능을 추가했습니다.
- **결과**: 플레이어 입력에 대한 정확한 시각적/기능적 제약 조건을 적용하여 스킬 남용 및 어색한 애니메이션 출력을 방지했습니다.

## ❗ 이슈 및 블로커
- **문제 (아이템 사용 불가 버그)**: 테스트 중 아이템이 정상적으로 사용되지 않는 이슈가 발생했습니다.
- **원인**: 아이템 관련 `enum`의 변수명을 수정하는 과정에서, 이를 참조하는 다른 스크립트들에 변경 사항이 일괄적으로 반영되지 않아 발생한 참조 오류입니다.
- **대응 방안**: 향후 코드 내 변수명이나 구조체 이름을 변경할 때는 반드시 IDE의 **'Rename Symbol(이름 바꾸기)'** 기능을 사용하여 연관된 모든 참조가 누락 없이 수정되도록 주의할 예정입니다.
