## ✅ 완료한 작업

### 1. UI 시스템의 리팩토링 작업
- **내용**: 각 Presenter가 UI 프리팹을 가지던 불편한 구조를 폐기하고 UIManager 인스턴스가 모든 UI를 타입(Type)으로서 구분 및 관리하는 구조로 변경함.
- **결과**: UI와 시스템 스크립트 간의 역할을 분명히 분리할 수 있도록 코드를 수정하여 전체적인 UI 관리 구조를 개선함.

### 2. 아이템 사용을 위한 기반 마련
- **내용**: 아이템 효과를 처리하는 클래스를 선언하고, 소모품 아이템 클래스의 데이터를 추가함.
- **결과**: 추후 구현될 아이템 사용 및 효과 적용 로직의 기반 데이터를 확립함.

### 3. 플레이어 UI 개편 및 공격 시 마나 소모
- **내용**: 플레이어의 체력, 마나, 퀵슬롯 UI를 기획서에 맞게 수정하고, 공격 시 무기의 종류에 따라 마나를 소비하며 마나 UI를 업데이트하도록 구현함.
- **결과**: 기획 의도에 부합하는 리소스 관리(마나 소비) 및 사용자 UI 환경을 조성함.

## 🛠️ 트러블 슈팅 (선택)

1. **문제 상황**: UI 기능을 구현하는 데 있어 다양한 종류의 UI 프리팹을 어떻게 일괄적으로 관리할 지에 대해 고민함.
2. **발생 조건**: 다수의 UI 컴포넌트와 프리팹이 존재할 때 이를 개별적으로 참조하고 관리해야 하는 비효율성 발생.
3. **해결 방법**: UIManager에 모든 UI 프리팹을 일괄 등록하고 'Type'을 사용하여 UI의 종류를 구분하는 구조로 완성하여 관리를 일원화함.
