## ✅ 완료한 작업

### 1. 벨크로 UI 가로 와이드 로비 배경 검수 및 통합
- **내용**: CP 장수영이 작업 및 연동한 로비 와이드 배경 파일 `Lobby_Controller_Concept_v2.1.png`에 대해 해상도 대응력(Canvas Scaler)과 벨크로 UI 레이아웃과의 비주얼적 동적 조화 가능성을 전수 기획 검수했습니다.
- **결과**: 가로 와이드 해상도 비율이 벨크로 연출 시의 화면 찢어짐 없이 안정적으로 동작함을 최종 확정했습니다.
- **관련 파일**: [Lobby_Controller_Concept_v2.1.png](file:///c:/GitHubProjects/Document_LucidDiver/Document_LucidDiver/LucidDiver_Document/06_이미지_작업물/03_UI_프레임_배경/Lobby_Controller_Concept_v2.1.png)

### 2. 신규 UI 그래픽 리소스 (77종) 기획 정합성 검사
- **내용**: OneDrive 작업 폴더에서 자동 이관 분류된 엠블럼, HUD 슬라이더, 퀵슬롯 아이콘, 등급별 슬롯 테두리 등 총 77종의 신규 스프라이트 파일에 대해 파일명 네이밍 컨벤션 매칭, 해상도 크기 깨짐 여부를 전수 정밀 기획 검수했습니다.
- **결과**: 오류 없이 분류가 완료되었음을 확인하고 차주 유니티 UI Canvas 프리팹 내부 대치 작업을 승인했습니다.
- **관련 파일**: [ui_resources_analysis.md](file:///c:/GitHubProjects/Document_LucidDiver/Document_LucidDiver/LucidDiver_Document/06_이미지_작업물/ui_resources_analysis.md)

### 3. 아이템 상자 구역별 랜덤 스폰 시스템 설계 및 구현
- **내용**: 
  - 단순히 맵 상에 아이템 상자를 무작위 살포하는 방식 대신, 특정 구역(예: 물류 창고 등)의 최소 생성 보장량(`guaranteedSpawnCount`)과 밀도 가중치(`densityMultiplier`)에 의거하여 스폰되도록 보정하는 `LevelBoxSpawner.cs` 및 `BoxSpawnZone.cs` 스크립트를 구현했습니다.
  - `SpawnManager.cs` 및 `GameManager.cs`에 스폰 생명주기를 연동하여 씬 로드 직후 1회 상자 랜덤 생성이 안정적으로 동작하도록 처리했습니다.
- **결과**: 레벨 디자이너가 하이라키 상에서 포인트를 손쉽게 관리하고 밀도를 컨트롤할 수 있는 환경이 조성되었습니다.
- **관련 파일**: [BoxSpawnPoint.cs](file:///c:/GitHubProjects/Document_LucidDiver/Document_LucidDiver/Assets/02_Scripts/Manager/BoxSpawnPoint.cs), [BoxSpawnZone.cs](file:///c:/GitHubProjects/Document_LucidDiver/Document_LucidDiver/Assets/02_Scripts/Manager/BoxSpawnZone.cs)

### 4. 에너미 AI 구조 다층 모듈화 및 2연격 콤보 돌진 시스템 구현
- **내용**:
  - 기존 단일 `EnemyMovement.cs`에 모여 있던 시야/소음 감지, 이동, 전투 책임을 각각 `EnemyBrain`, `EnemyPerception`, `EnemyNoiseListener`, `EnemyLocomotion`, `EnemyCombat` 클래스로 분리 리팩터링을 완수했습니다.
  - 하나의 공격 애니메이션 내에 2개의 프레임 이벤트(`GetAttack1`, `GetAttack2`)를 배치하고 이를 `EnemyAnimator`와 프레젠터가 중간에 가로채어 각 스윙의 타이밍(인덱스)에 맞게 개별 돌진 거리(`LungeDistance`), 속도, 피해가 독립적으로 인가되도록 연격 시스템을 구현했습니다.
- **결과**: 적이 허공을 때리지 않고 플레이어를 타깃하여 위협적으로 몰아치는 2연격 전투 템포를 완성하고, 향후 AI 전술 확장이 용이한 모듈형 구조를 구축했습니다.
- **관련 파일**: [EnemyMovement.cs](file:///c:/GitHubProjects/Document_LucidDiver/Document_LucidDiver/Assets/02_Scripts/System/Enemy/EnemyMovement.cs) 등

## 🛠️ 트러블 슈팅 (선택)
1. **문제 상황**: 상자 개방이나 수직 높이가 높은 앵커에서 소음 발생 시 적 AI가 조사 위치로 이동하다 멈춤(Stuck) 현상 발생.
2. **발생 조건**: 소음 앵커의 수직 좌표 Y값이 유효 NavMesh 구역의 바닥면을 벗어났을 때.
3. **해결 방법**: `NavMesh.SamplePosition` API를 런타임 역탐지 연산에 결합하여 수직 위치 오차를 샘플링하고 오프셋을 바닥 좌표로 자동 보정하여 안전하게 해결했습니다.
