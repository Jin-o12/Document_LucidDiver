## 🛠️ 트러블 슈팅 (선택)

1. **문제 상황**: 소음 감지 후 조사 또는 추격 어그로가 해제되었을 때, 여러 마리의 에너미가 각각의 원래 순찰 동선으로 가지 못하고 공통된 기준 좌표로 모이거나 동일한 위치로 뭉치며, 특정 장애물 차폐 시 조사를 무한 유지하는 문제.
2. **발생 조건**: 복귀 시 기준점이 개별 이탈 시작 시점의 위치가 아니거나, 목적지에 영구적으로 도달할 수 없는 NavMesh 장애를 만났을 때.
3. **해결 방법**: `EnemyNoiseListener`에 소음 조사 최대 시간(Timeout) 타이밍 제한을 도입하여 Stuck을 강제 차단하고, `EnemyMemory` 컴포넌트를 이용해 이탈 직전의 시작점 좌표와 해당 순찰 인덱스를 각 개체별로 로컬 세이브 및 복귀 목표로 할당하여 복귀 후 원래 순찰을 바로 갱신하도록 처리해 이를 해결했습니다.
