## ✅ 완료한 작업

### 1. 데이터 기반 VFX 시스템 구축
- **내용**: 
  - `GameplayVFXIds`에 인게임 사용 VFX 식별자를 전역 정의함.
  - `VFXCatalog` ScriptableObject에서 ID별 프리팹, 스케일, 회전, 수명, 풀 수량 설정 구조 구축.
  - `VFXContext`를 통해 위치, 회전, 부모, 추가 스케일 등 재생 정보를 전달함.
  - `VFXService` 및 `VFXRuntimePool` 구현을 통한 대여·반환 로직 작성.
  - `PooledVFX`의 수명 또는 파티클 종료 시점 자동 풀 반환 로직 적용.
  - `GameplayVFXPresenter`를 통해 게임 내 이벤트를 VFX 재생으로 변환.
- **결과**: VFX의 런타임 오브젝트 풀링 및 효율적인 자원 관리 시스템 구축 완료.

### 2. 전체 인게임 이벤트 VFX 연결
- **내용**: 
  - 플레이어 이동, 회피, 피격, 사망, 무기 공격 이벤트에 VFX 연계.
  - 에너미 피격, 공격, 사망 이벤트 연계.
  - 아이템 드롭, 습득, 상자 개방, 아티팩트 장착 이벤트 연계.
  - 문 상호작용 및 탈출 지점에 VFX 적용.
- **결과**: 인게임 주요 액션에 시각 피드백 연결 및 연출 정합성 확보.

### 3. 유탄 스킬 VFX 단계 분리
- **내용**: 
  - 유탄 던지는 시점의 투척체 효과 분리.
  - 일정 시간 후 생기는 프리즘 폭발 효과 분리.
  - 폭발 후 발현되는 디코이 효과를 독립적인 카탈로그 항목으로 설정.
- **결과**: 유탄 스킬 전반의 시인성 및 퀄리티 개선.

### 4. VFX 풀 반환 오류 수정
- **내용**: 
  - `OnDisable`에서 풀 반환을 처리하며 중복으로 `SetActive(false)`를 호출하던 비정상 로직 제거.
  - `OnDisable`에서는 부모 복원과 대기열 등록만 수행하도록 역할 분리.
  - 상자 오픈 또는 아이템 장착 후 VFX 지속 현상에 대해 카탈로그 수명 제한 설정 병행.
- **결과**: 중복 풀 반환으로 인한 인스턴스 소실 또는 에러 해결.

### 5. VFX 카탈로그 설정 반영
- **내용**: 
  - 플레이 모드 중 수정한 프리팹, 스케일, 수명 등의 값을 휘발되지 않도록 `VFXCatalog` 에셋에 반영.
- **결과**: 런타임 테스트를 통한 수치 최적화 결과 영구 보존.

### 6. 튜토리얼 씬 기본 구성

## 오늘의 핵심 결정

| 항목 | 결정 |
| --- | --- |
| **VFX 식별 방식** | 코드 상수 ID와 ScriptableObject 카탈로그를 병행 사용 |
| **VFX 로딩** | `VFXService`가 카탈로그 정보를 읽어 런타임 풀을 제어 |
| **풀 반환** | 명시적 비활성화와 OnDisable 대기열 등록 책임을 완전 분리 |
| **유탄 VFX** | 투척체 -> 프리즘 폭발 -> 디코이 발현 3단계 분리 구성 |
| **튜토리얼 방식** | `TutorialScene`에서 독립 완성 후 프리팹 방식으로 타 씬 이식성 제공 |
| **팝업 실행** | 콜라이더 감지 트리거 및 `TutorialEventBridge` 이벤트 핸들링 결합 |
| **씬 구성** | 베이스 씬(공통 매니저) + 콘텐츠 씬(튜토리얼 맵/트리거) Additive 방식 |
| **NavMesh** | `TutorialScene` 전용 Surface 및 독립 에셋 베이크 적용 |
| **문서 범위** | 직접 구현·수정한 코드만 분리해 문서화하고 팀원 변경 사항 제외 |

## ❗ 이슈 및 블로커
- **Additive 씬 구동 확인**:
  - `TutorialScene`은 공통 매니저 및 플레이어가 있는 베이스 씬과 Additive로 로드해야만 정상 구동됨.
- **입력 맵 충돌 관리**:
  - 팝업 노출로 일시 정지(`timeScale = 0`)될 때, 상자 UI 등의 입력이 오작동하지 않는지 실제 검증 필요.
- **VFX 파티클 루프 예외**:
  - 프리팹 파티클이 Loop 속성일 경우 자동 풀 반환이 막힐 수 있으므로 카탈로그 내 수명 기반 반환 강제 병행 필수.
- **NavMesh 에셋 정합성**:
  - 복제 씬 생성으로 인해 에셋 레퍼런스 손실 오류가 잦아 향후 씬 이식 시 재참조 주의 필요.
