## ✅ 완료한 작업

### 1. 에너미 돌진 공격 및 공격 판정 벽 관통 보정
- **내용**:
  - **돌진 중 벽 관통**: 에너미 돌진 공격 시 플레이어가 벽 근처에 있을 때 돌진 목적지가 벽 너머 좌표로 잡히는 현상을 해결하기 위해, 목적지 계산 후 NavMesh 및 Wall Collider 기준으로 안전 지대를 검사하고 벽 앞 버퍼 지점으로 목적지를 보정하도록 개선.
  - **벽 너머 공격 판정**: 공격 데미지 적용 직전에 에너미와 플레이어 사이에 벽(Wall Layer)이 존재하는지 검사하는 차단 로직을 추가하여 벽 너머의 대상에게 데미지가 들어가지 않도록 조치.
- **결과**: 돌진 공격이 벽을 뚫고 나가지 않으며 벽 뒤의 플레이어를 공격할 수 없도록 수정 완료.

### 2. 플레이어 구르기 및 이동 충돌 보정
- **내용**:
  - **구르기 벽 관통**: 플레이어가 벽면을 따라 비비며 구르기 사용 시 모서리나 충돌 겹침 지점에서 관통하는 문제를 해결하기 위해 구르기 진행 중에만 SweepTest 및 SphereCast 보정을 활성화하도록 수정 (일반 이동 전체에 적용 시 문 이동/상호작용 방해를 최소화하기 위함).
  - **이동 잔여 속도**: 벽에 접촉한 후 입력을 떼었음에도 관성/수평 잔여 속도로 밀려 나가는 오작동을 막기 위해 이동 후 수평 속도 강제 초기화 처리 추가.
- **결과**: 모서리 충돌 신뢰성 상승 및 정지 관성 보정 완료.

### 3. 플레이어 총격 null 참조 예외 디버깅
- **내용**:
  - **원인**: 총격 Raycast가 벽이나 FenceCollider에 적중할 때, 해당 오브젝트에 데미지 수신 컴포넌트가 존재하지 않아 target 변수가 null인 상태에서 디버그 로그가 이 null target을 직접 참조하면서 콘솔 에러를 유발함.
  - **조치**: target 유효성 검사 블록 내에서만 로그 출력을 실행하도록 구조를 수정하여 null 참조 에러 방지.
- **결과**: 벽/팬스 타격 시 발생하던 콘솔 에러 로그 해소.

### 4. 에픽 아티팩트 아이콘 로드 실패 문제 조치 (Addressables)
- **내용**:
  - **원인**: 에픽 아티팩트 아이콘의 Key 값은 JSON 데이터 상에 정의되어 있으나, Addressables Groups 설정에 등록되지 않아 리소스 로드 불가 에러가 발생함.
  - **조치**: 누락된 리소스를 Addressables Default Local Group에 정상적으로 등록 완료.
- **결과**: 인게임에서 에픽 아티팩트 아이콘이 깨지지 않고 정상 출력됨.
