### 4. 소음 위치 앵커 및 경로 보정
- **내용**:
  - `NoiseSourceObject.cs`를 생성하여 월드 상에 소음 앵커를 배치하고, 적 AI가 이 앵커 위치를 참조하여 조사 경로를 갱신하도록 구성했습니다.
  - 소리가 NavMesh 외부 영역이나 상자 위 등의 유효하지 않은 좌표에 생길 경우를 대비해 `NavMesh.SamplePosition`을 활용하여 유효 좌표로 목적지를 자동 보정하도록 안전장치를 넣었습니다.
- **결과**: 비정상적인 위치에 앵커가 생성되어도 AI가 경로를 잃지 않고 정상적으로 작동하도록 예외 처리를 완료했습니다.

## 🛠️ 트러블 슈팅 (선택)

1. **문제 상황**: 공중에 있거나 상자 내부/위에 위치한 소음 앵커 좌표를 적 AI가 목적지로 직접 설정할 때, 이동 경로를 계산하지 못해 제자리에 멈춰 서는 현상 발생.
2. **발생 조건**: 상자 개방(`ChestOpen`) 시 상자의 중심 높이가 NavMesh의 수직 유효 범위를 벗어났을 때.
3. **해결 방법**: `EnemyMovement`가 조사 경로를 설정할 때, 앵커의 원본 `Position`을 직접 사용하는 대신 `NavMesh.SamplePosition`을 거쳐 가장 가까운 바닥(유효 NavMesh 영역)으로 보정된 좌표를 최종 목적지로 할당하여 예외 현상을 차단함.
