## ✅ 완료한 작업

*(관련 커밋: `60122ec`, `011771c`, `424edea`)*

### 1. 전투 실습 구간 진행 차단 및 시작 조건 분리
- **내용**: Step3 전투 실습 트리거의 자식으로 배치된 CombatCollider 제어 구현 및 활성화 시점을 변경(접촉 시점 → 안내 데이터 처리 시점)했습니다.
- **결과**: 전투 실습 안내 시작 후 앞/뒤 차단 콜라이더가 활성화되며, 적 처치(`GlobalEventBus.OnEnemyDead`) 시 차단 콜라이더가 정상 해제됩니다. 또한 너무 일찍 차단되어 바닥 아래로 떨어지던 현상을 보정했습니다.
- **핵심 결정**: 
  - 전투 차단 콜라이더는 Step3 안내가 실제로 처리된 뒤 활성화.
  - 전투 실습 완료는 적 사망 이벤트로 판단하고 앞·뒤 차단을 해제.

### 2. 튜토리얼 UI 입력 누수 수정 및 HUD 흐림 처리
- **내용**: `LocalInputReader`에 `isGameplayInputBlocked` 상태를 추가해 UI가 켜질 때 모든 입력(이동, 공격, 스킬 등)을 차단하도록 하고, HUD 알파 투명도 조절 이벤트(`GlobalEventBus.OnGameplayHUDAlphaRequested`)를 적용했습니다.
- **결과**: UI 확인 버튼을 누를 때 닫힘 처리가 총 발사 등 게임 액션으로 이어지는 누수를 막았으며(프레임 단위 지연), 튜토리얼 대화창이 열렸을 때 인게임 HUD 투명도가 0.3으로 옅어져 가독성이 향상되었습니다.

### 3. 튜토리얼 UI 배치를 프리팹·인스펙터 제어로 전환
- **내용**: `TutorialPopup` 스크립트 런타임에서 RectTransform 위치/크기를 강제로 덮어쓰던 처리를 제거하고, Objective 패널 닫기와 목표 완료 이벤트를 분리했습니다.
- **결과**: UI 위치, 크기, 배경 이미지 등 시각적인 요소는 프리팹과 인스펙터 설정에 맞춰 제어되도록 안정화되었습니다. 플레이어가 안내창을 닫아도 이벤트 추적은 유지됩니다.

### 4. 튜토리얼 전투 실습 사망 방지 및 관제사 무전 연동
- **내용**: 튜토리얼 씬 한정으로, 플레이어가 치명적인 피해를 받아도 체력을 1로 고정하도록 예외 처리하고 관제사 경고 무전 기능을 구현했습니다.
- **결과**: 사망하여 로비로 튕기는 대신 "에너미를 죽여야 해!"라는 경고 무전과 함께 TimeScale이 정지되며, 전투에 재진입할 수 있도록 기존 튜토리얼 가이드를 복구시킵니다.

### 5. 문서 및 기록 정리
- **내용**: 오늘 직접 작성한 3건의 커밋 내역(SongYeChan1024)을 바탕으로 코드 변경 기록과 전체 스크립트 비교 문서를 작성했습니다.

## ❗ 이슈 및 블로커
- **콜라이더 해제 조건**: `OnEnemyDead`가 특정 적의 ID를 확인하지 않아, 다른 적이 죽어도 차단 콜라이더가 해제될 가능성이 있음.
- **적 HP 설정 공통화 문제**: `EnemyStatus.hpMax = 50` 코드가 공통 스크립트에 적용되어 다크 스피릿이 아닌 다른 에너미에게도 영향을 줄 수 있음 (프리팹 또는 데이터 기반 수치로 분리 논의 필요).
- **입력 경고**: `PlayerInput`이 비활성화된 상태에서 액션맵 전환을 호출하면 InputSystem 경고가 발생할 수 있음.
- **기타 확인 사항**: 
  - `TutorialPopup.cs` 내 한글 주석이 커밋 diff에서 깨져 보여 파일 인코딩(UTF-8 등) 확인 필요.
  - `SampleSceneProfile.asset`이 튜토리얼 커밋에 포함되어 있어 전역 렌더 설정 변경이 의도된 것인지 검토 필요.
