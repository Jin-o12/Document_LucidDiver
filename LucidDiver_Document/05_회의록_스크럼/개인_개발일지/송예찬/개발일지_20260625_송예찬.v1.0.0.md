## ✅ 완료한 작업

### 1. 컨테이너 박스 및 인벤토리 양방향 슬롯 이동 연동 분석 및 검증
- **내용**: 
  - **`ItemBox.cs` 개편**: 동적 리스트 형태에서 고정된 슬롯 개수(`slotCapacity` = 8) 구조로 변경했습니다. 슬롯 자체는 삭제되지 않고 빈 칸 상태(`CreateEmptyEntry`)를 유지하며, 인벤토리로부터의 입력 초과분을 계산하여 반환하는 `TryAddItem` 및 `TryAddToSlot`을 구현했습니다.
  - **`InventorySlotData.cs` 확장**: 원본 데이터인 `ItemData` 필드를 데이터 스키마에 추가하여 상자와 인벤토리 간 이동 시 스택 상한치(`itemMultiple`) 등의 속성을 소실 없이 즉각 파악 가능하게 했습니다.
  - **`PlayerInventory.cs` 고도화**: 단일 지정 슬롯에 대한 타겟 삽입(`TryAddToSlot`) 및 청소(`ClearSlot`)를 적용하고, 교환 이벤트 시 `itemData` 필드도 같이 튜플 스왑되도록 방어 코드를 매핑했습니다.
  - **`ChestUI.cs` 정적 최적화**: 매 이동 시마다 모든 슬롯 UI를 파괴하고 재생성(Instantiate)하던 방식에서 기존 슬롯 오브젝트 개수가 유지될 시 컴포넌트 정보만 갈아 끼우는 갱신 구조(`RefreshAll`/`RefreshSlot`)로 변경해 GC 오버헤드를 감소시켰습니다. 또한, `TryMoveToInventorySlot`, `TryMoveFromInventorySlot`을 통해 마우스 드래그 앤 드롭 이동을 지원하는 기반 인터페이스 함수를 완성했습니다.
- **결과**: 인벤토리 가득 참 등 예외 상황에서 아이템 초과 수량이 안전하게 유지되며, 상자 UI 슬롯 오브젝트의 정적 갱신을 통해 UI 비동기 로드 시의 비정상 메모리 접근 및 Null Reference 예외 위험성을 원천 차단했습니다.

## ❗ 이슈 및 블로커
