## 🛠️ 트러블 슈팅 (선택)

### 1. UI 캔버스 전환 시 Live2D 재생 정지 현상 해결
1. **문제 상황**: 로비 탭(창고, 다이버 기록, 출격 준비 등)을 이동하여 화면을 바꾼 후 다시 진입하면 Live2D 캐릭터 일러스트가 멈춘 상태로 화면에 먹통이 되는 현상 발생.
2. **발생 조건**: `LobbyUIPresenter`가 각 캔버스 패널을 파괴하지 않고 캐싱한 채 `SetActive(true/false)`로 화면을 토글할 때 발생.
3. **해결 방법**:
   - `UILive2DPlayer.cs`에서 재생 트리거가 최초 1회만 호출되는 `Start()`에 있었던 것을 매번 활성화될 때마다 실행되는 **`OnEnable()`**로 이식하여 비디오 재생이 정상 재개되도록 했습니다.
   - 또한 **`OnDisable()`** 수명주기를 추가하고 내부에서 `StopVideo()`를 연동하여 화면이 꺼졌을 때는 `RenderTexture` 자원을 깨끗하게 릴리즈(GPU/메모리 최적화)하도록 설계했습니다.
   - **결과**: 캔버스 전환 시 에러나 캐시 오버헤드 없이 실시간으로 Live2D 애니메이션이 정상 재생됩니다.
