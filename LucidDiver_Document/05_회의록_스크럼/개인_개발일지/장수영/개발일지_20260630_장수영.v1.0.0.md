  - 4개 코너 탈출구(전화부스) 텍스트 명세 보완.
  - 마트 북쪽 창고 변형 구조 명세화 및 기억 파편 맵 전체 랜덤 스폰 규칙 반영.

### 3. 로비/데모 씬 UI 필요 그래픽 리소스 도출
- **내용**: 로비씬과 데모씬에 존재하는 8종의 핵심 UI Canvas 프리팹을 전수 조사하여, 런타임에 쓰이는 이미지 리소스 중 교체 또는 추가가 필요한 영역 분석.
- **결과**: 유안 전신 스탠딩 및 초상화, 기묘한 사탕/변질된 붕대 아이콘, UI 슬롯 프레임 등 세부 그래픽 리소스 요구사항 목록을 정리하여 별도 문서로 발행.
- **관련 파일**: [ui_resources_analysis.md](file:///c:/Project/Document_LucidDiver/LucidDiver_Document/06_%EC%9D%B4%EB%AF%B8%EC%A7%80_%EC%9E%91%EC%97%85%EB%AC%BC/ui_resources_analysis.md)

### 4. 시야 가림 장애물 반투명화(Occluder Fade) 구현 가능성 조사
- **내용**: 쿼터뷰 시점 내 가구 및 벽체에 의한 캐릭터 시야 차단을 보완하기 위해 프로젝트 URP 설정 및 가상 카메라 구조 검사.
