### 1. 발표 웹 코드 최적화 — CSS/JS 외부 파일 분리
- **내용**:
  - `index.html` 단일 파일(5,879줄)에 혼재되어 있던 CSS와 JS를 외부 파일로 분리.
  - `<style>` → `style.css`(1,639줄), `<script>` → `script.js`(629줄).
  - AI 에이전트를 활용하여 중복 CSS/JS 블록 탐지 및 리팩토링, 렌더링 차단 버그 디버깅을 수행. 부족한 웹 프론트엔드(HTML/CSS/JS) 실력을 AI로 대거 보충하여 구현 시간을 크게 단축함.
- **결과**: `index.html`이 순수 HTML 콘텐츠 1,062줄만 남아 슬라이드 삽입/수정 작업 용이성 극대화.
- **관련 파일**: 
  - `web/presentation/index.html` (1,062줄)
  - `web/presentation/style.css` (신규)
  - `web/presentation/script.js` (신규)

### 2. 디자인 챌린지(CH02) 마우스 반응형 듀얼 배경 + SYNC 키비주얼 전환 연출
- **내용**:
  - 서브컬처(블루아카이브 레퍼런스) ↔ 익스트랙션(타르코프 레퍼런스) 배경 이미지 2장을 마우스 X좌표에 따라 교차 페이드하는 연출 구현.
  - 전환 감도를 화면 30%~70% 구간 집중 리매핑, 최대 opacity 0.6으로 조정하여 카드 중반에서 풀 전환 달성.
  - "잃어야 하는 장르와 잃어선 안 되는 장르를 어떻게 결합할 것인가?" 핵심 문구 삽입.
  - `?` 버튼 클릭 → SYNC 전환 시 마우스 트래킹 중단 + 루시드 다이버 키비주얼(`CP_Challenge_Resolved_KeyVisual.jpg`)로 배경 완전 교체.
  - 비네트 오버레이 z-index 통일로 텍스트 가독성 보장.
- **결과**: 장르 모순 → 해결의 시각적 스토리텔링이 마우스 인터랙션으로 체험 가능한 연출 완성.
- **관련 파일**:
  - `web/presentation/assets/[CP]장수영/images/CP_Challenge_Subculture_Ref.jfif` (신규)
  - `web/presentation/assets/[CP]장수영/images/CP_Challenge_Extraction_Ref.jfif` (신규)
  - `web/presentation/assets/[CP]장수영/images/CP_Challenge_Resolved_KeyVisual.jpg` (Game_BG.jpg에서 리네임)
