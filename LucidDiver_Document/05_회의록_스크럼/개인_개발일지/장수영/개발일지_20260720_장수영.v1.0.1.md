### 3. AnyPortrait 캐릭터 그림자 투명화 및 렌더 큐 제외 버그 수정
- **내용**:
  - **기본값 수정**: `AnimatorShadowSync.cs`의 투명도 제어 변수 `targetShadowAlpha`가 선언 시 기본값 `0f`(완전 투명)로 셋업되어 그림자가 보이지 않던 문제를 기본값 `1f`로 코드 수정하고, 캐릭터 프리팹 3종의 직렬화된 인스펙터 값을 `1.0`으로 복원함.
  - **렌더링 큐 스왑 및 동적 셰이더 교체**: AnyPortrait의 기본 셰이더(`apSG_URP16_2021_Lit_T_Alpha`)가 반투명(RenderQueue 3000)으로 잡혀 URP 섀도우 맵 생성 단계(RenderQueue <= 2500)에서 완전히 배제되던 문제를 우회하기 위해, 그림자 머티리얼을 셰이더 알파 클리핑 대응 버전(`_C_Alpha`, 예: `apSG_URP16_2021_Lit_C_Alpha`)으로 런타임 첫 프레임에 동적 스왑하고 Render Queue를 2450으로 강제 수정하도록 코드 보완. (GC 부하 최소화)
- **결과**: 2D 캐릭터 스프라이트가 투명 영역을 가진 채로 섀도우 캐스터 패스에 정상 진입하여 실시간 그림자를 정상 캐스팅함.
- **관련 파일**:
  - `AnimatorShadowSync.cs`
  - 캐릭터 프리팹 3종

### 4. URP 렌더러 필터 마스크 수정 및 그림자 해상도/바이어스 튜닝
- **내용**:
  - **레이어 필터 활성화**: URP Renderer 에셋 2종(`[FlatKit] Example Renderer` 및 `[FlatKit] Example Character Renderer`)의 Opaque/Transparent 마스크에서 차단되어 있던 Layer 14 (Shadow) 레이어를 활성화하여 그림자 복제본이 정상적으로 드로우되도록 수정.
  - **바이어스 및 그림자 퀄리티 개선**: 기존 1.0이라는 극단적으로 높은 값으로 지정되어 실루엣이 뭉뚱그려지던 Pipeline 에셋(`[FlatKit] Example URP Asset`)의 Depth Bias와 Normal Bias를 `0.1`로 튜닝하여 날카롭고 뚜렷한 2D 실루엣을 구현. 추가 광원(플래시라이트)의 그림자 해상도를 1024로 높이고 그림자 한계 거리를 35로 지정.
- **결과**: 플래시라이트 조명 아래에서도 2D 캐릭터 본연의 날카로운 실루엣 그림자가 바닥에 왜곡 없이 맺히도록 최적화 완료.
- **관련 파일**:
  - URP Pipeline 에셋 및 Renderer 에셋 2종

## 🛠️ 트러블 슈팅

### URP Transparent 반투명 섀도우 맵 생성 배제 문제
1. **문제 상황**: 플래시라이트를 비추거나 방향 광원이 비추어도 AnyPortrait 캐릭터의 실시간 그림자가 바닥에 전혀 나타나지 않고, 그림자 복제본이 씬에 배치되어도 무시됨.
2. **발생 조건**: AnyPortrait 반투명 기본 셰이더(`apSG_URP16_2021_Lit_T_Alpha`)를 적용하여 런타임 렌더 큐가 3000(Transparent)이 되는 경우, Unity URP 섀도우 연산(Opaque 2500 이하만 처리)에서 제외됨.
3. **해결 방법**: `AnimatorShadowSync.cs` 스크립트를 수정하여, 첫 런타임 프레임에 그림자 머티리얼의 셰이더를 투명(Cutout) 지원 셰이더(`_C_Alpha` 계열)로 교체하고, 머티리얼의 `renderQueue`를 2450으로 강제 변경하여 섀도우 맵 연산에 편입시킴으로써 실시간 그림자를 완벽히 복원함.
