### 1. PM 완성 영상 첫 진입 시 로딩 화면 고정
1. **문제 상황**: `꿈식자 AI — 완성 결과` 장면에 처음 들어가면 비디오가 준비되어 있어도 로딩 플레이스홀더가 계속 표시되었습니다.
2. **발생 조건**: 이전 슬라이드에서 PM 01 장면으로 바로 이동할 때 발생하며, 다른 상태 GIF를 선택한 뒤 `전체 루프`로 돌아오면 정상 재생되었습니다.
3. **해결 방법**: 장면 진입 시 전체 루프 상태를 다시 초기화하고, 영상의 메타데이터·데이터·재생 가능 이벤트마다 표시 상태를 동기화했습니다. 결과적으로 첫 진입부터 영상 컨트롤이 표시됩니다.

### 2. CD 발표자료 Markdown 프리뷰 실패
1. **문제 상황**: 우성혁 CD 발표자료가 IDE Markdown 미리보기에서 정상 렌더링되지 않았습니다.
2. **발생 조건**: 비표준 체크박스 문자, 대괄호가 포함된 상대 경로, 비표준 표 구분선이 함께 존재할 때 발생했습니다.
3. **해결 방법**: 표준 `[x]` 체크박스와 표 문법으로 정리하고 `[CD]` 경로를 URL 인코딩해 미리보기 호환성을 복구했습니다.

### 3. 비교 연출과 코드 이미지의 화면 잘림
1. **문제 상황**: CD의 `Stop3DSound` 옆 코드 이미지 일부가 카드 바깥으로 잘리고, 발표자별 Before/After 조작 방식도 서로 달랐습니다.
2. **발생 조건**: 고정 높이 카드 안에서 원본 비율이 다른 이미지·영상에 동일한 크기 규칙을 적용할 때 발생했습니다.
3. **해결 방법**: `min-height: 0`, `overflow: hidden`, `object-fit: contain` 조합으로 미디어 영역을 안정화하고, PD 비교 슬라이더를 공통 구조로 확장했습니다.
