## 🛠️ 트러블 슈팅

### 1. GitHub Pages에서 Notion 임베드 페이지 404 발생

1. **문제 상황**: 프레젠테이션 웹은 정상 작동했지만 `web/Notion_embed/` 주소는 GitHub Pages에서 404를 반환했습니다.
2. **발생 조건**: 디렉터리의 진입 파일이 대문자 `Index.html`로 저장되어 있었고, URL에서는 파일명을 생략한 디렉터리 주소로 접근했습니다.
3. **해결 방법**: GitHub Pages가 찾는 소문자 `index.html`로 파일명을 변경하고 Git의 인덱스에도 대소문자 변경을 명시적으로 반영했습니다.

### 2. 파일 클릭 시 Notion을 벗어나 GitHub 새 페이지가 열림

1. **문제 상황**: 기존 탐색기의 파일 항목이 GitHub `blob` 주소를 새 탭으로 여는 링크여서 Notion 임베드 안에서 문서를 연속적으로 확인할 수 없었습니다.
2. **발생 조건**: 파일 이름이 `<a target="_blank">` 요소로 생성되어 모든 파일 클릭이 외부 이동으로 처리되었습니다.
3. **해결 방법**: 파일 클릭을 `loadFile()` 이벤트로 교체하고 Raw 파일을 가져와 우측 패널에 Markdown·코드·미디어 형식으로 렌더링했습니다. 외부 이동은 별도의 `GitHub에서 열기` 버튼으로 분리했습니다.

### 3. 저장소 전체 폴더가 노출되어 문서 탐색이 복잡함

1. **문제 상황**: Notion 사용 목적과 관계없는 `web`, `Templates`, 루트 스크립트까지 파일 트리에 표시되었습니다.
2. **발생 조건**: GitHub Trees API가 반환한 저장소 전체 항목을 그대로 트리로 구성했습니다.
3. **해결 방법**: `rootPath`를 `LucidDiver_Document`로 지정하고, 경로가 동일하거나 해당 경로로 시작하는 항목만 `scopedItems`로 분리해 탐색기·검색·개수 계산에 사용했습니다.
