## ✅ 완료한 작업

### 1. 플레이어 캐릭터 전방향 애니메이션 클립 전종 완성
- **내용**: 어제 진행 중이던 후방측면을 포함, 인게임 플레이어에게 필요한 모든 애니메이션 클립을 AnyPortrait 내에서 완성했습니다. 완성 목록은 다음과 같습니다.

  | 구분 | 클립명 | 비고 |
  |---|---|---|
  | 측전방 | Idle / Walk / Run | 개선 완료 (품질 향상) |
  | 측전방 | Aim / Fire | 조준·격발 |
  | 측전방 | Hit (피격) | 얼굴 스프라이트 교체 연동 |
  | 측후방 | Idle / Walk / Run | 신규 완성 |
  | 측후방 | Aim / Fire | 조준·격발 |
  | 전후 통합 | Death (죽음) | 전방·후방 공용 클립 |
  | 전후 통합 | Near-Death Loop (빈사 루프) | 전방·후방 공용 루프 |

- **결과**: 플레이어 인게임 표현에 필요한 전 방향 × 전 상태 애니메이션 클립 완전 완료. **배포만 남은 상태.**

---

### 2. 측전방 애니메이션 3종 품질 개선
- **내용**: 전일(06-25) 작성한 측전방 Idle / Walk / Run 클립의 모션 흐름과 타이밍을 재검토하여 자연스러움이 부족한 구간을 수정·개선했습니다.
- **결과**: 측전방 기본 모션 3종의 품질 향상 확인.

---

### 3. 피격 시 얼굴 스프라이트 교체 구현 (전방 한정)
- **내용**: 전방측면 피격(Hit) 상태에서 캐릭터 얼굴 부위의 스프라이트가 별도의 피격 표정 이미지로 교체되도록 AnyPortrait 내 스프라이트 스왑 기능을 활용하여 구현했습니다. 후방측면은 얼굴이 미노출되므로 전방 한정 적용입니다.
- **결과**: 피격 시 표정 변화 → 캐릭터 서브컬처 감성 표현 강화.

---

### 4. 죽음 / 빈사 루프 애니메이션 (전후방 통합 클립)
- **내용**: Death(죽음)와 Near-Death Loop(빈사 루프) 클립을 전방·후방 양쪽에서 공용으로 사용 가능한 통합 클립으로 제작했습니다. 방향에 따라 별도 클립을 관리하는 오버헤드를 제거하고 구조를 단순화했습니다.
- **결과**: 전후방 공용 사망·빈사 모션 완성, 상태 전환 로직 부담 최소화.

---

### 5. URP Lit 셰이더 적용 — 빛 상호작용 대응 (셰이더 그래프 수정)
- **내용**: 기존 픽셀 아트 캐릭터에 적용된 셰이더를 URP 환경에서 씬 조명과 정상적으로 상호작용하도록 **URP Lit** 기반으로 전환했습니다. URP Shader Graph를 수정하여 Lit 라이팅 모델을 연결하고, 픽셀 아트 특성(Point 필터링, Anti-aliasing 억제)을 유지한 채 조명 반응이 가능하도록 처리했습니다.
- **결과**: 씬 조명(Directional Light, Point Light 등)이 캐릭터에 정상 반영됨. URP 렌더 파이프라인 완전 대응.
- **관련 기술**: Unity 2022.3 URP, Shader Graph, Lit 라이팅 모델

---

### 6. 확장성 고려 리깅 및 메시 최적화
- **내용**: 향후 애니메이션 추가 및 파츠 교체(코스튬 확장 등)를 고려하여 본(Bone) 구조와 메시 정점(Vertex) 배치를 재검토했습니다. 불필요한 본을 제거하고, 가중치 영향 범위를 조정하여 런타임 부하를 낮추는 최적화를 적용했습니다.
- **결과**: 리깅 구조 경량화 및 유지보수 용이성 향상. 추후 코스튬 파츠 교체나 애니메이션 추가 시 재작업 최소화 기반 마련.
