## ❗ 이슈 및 블로커
- **이슈**: BOM 없는 UTF-8 파일 일괄 치환 시 파워쉘 인코딩 깨짐 현상 발생
- **해결**: 파워쉘 자체의 리터럴 한글 인코딩 오류를 우회하기 위해 C# 유니코드 16진수 매칭 방식을 사용한 치환 처리로 인코딩 깨짐 문제를 완벽히 해결함.

---

## 🛠️ 트러블 슈팅 (선택)
1. **문제 상황**: UTF-8 파일 일괄 치환 스크립트 실행 시, 파워쉘의 기본 인코딩 문제로 한글 텍스트(`채린` 등)가 에러를 일으키거나 결과물이 깨지는 현상.
2. **발생 조건**: Windows 환경의 파워쉘에서 UTF-8 인코딩이 지정되지 않은 상태로 한글 유니코드 문자열을 직접 매칭하여 파일에 쓰기 시도할 때 발생.
3. **해결 방법**: 파워쉘 메모리상에서 `[char]0xCC44 + [char]0xB9B0`와 같은 C# Char 유니코드 조합을 이용해 한글 단어를 생성한 뒤, 인코딩 옵션을 `-Encoding utf8`로 강제 지정하여 덮어씌움으로써 인코딩 유실 없는 깔끔한 치환을 보증함.
