- **관련 파일**: [01_SSOT_최종_기준문서](file:///c:/Project/Document_LucidDiver/LucidDiver_Document/01_SSOT_최종_기준문서), [02_개발_전달용](file:///c:/Project/Document_LucidDiver/LucidDiver_Document/02_개발_전달용) 등의 디렉토리 전면 개편

### 2. UI 플로우 문서의 실제 UI 이미지 레퍼런스 반영 및 명세 상세화
- **내용**: 텍스트(ASCII) 기반의 투박한 UI 레이아웃을 최신 GUI 디자인 레퍼런스 이미지로 매칭하고, 각 화면의 핵심 기능에 관한 설명글을 보강했습니다.
- **결과**: 
  - 로비 관제실, 출격 준비, 결과창(성공/실패), 다이버 기록 및 창고/인벤토리 화면에 맞게 최신 이미지를 연결했습니다.
  - 마우스 드래그 앤 드롭 및 더블 클릭 조작 명세, 전투용 퀵슬롯 장착 제약(P0 사양 상 슬롯 1, 2만 활성화), 기억 파편의 정산 시 자동 소모 및 레벨업-심상 기록 해금 라이프사이클 등을 구체적으로 서술하여 개발팀의 구현 가독성을 극대화했습니다 (문서 버전 v0.2 갱신).
