### 1. 설정 UI 구현 및 볼륨/풀스크린 기능 연동
- **내용**: 
  - 로비 화면의 옵션/설정 버튼 클릭 시 설정 패널이 화면 최상단에 안전하게 렌더링되도록 기능을 연동함. 로비 허브 UI 등 기존 레이아웃 아래에 묻히지 않도록 각 UI 캔버스의 `Sorting Order` 수치를 최적화함.
  - 마스터 및 BGM/SFX 볼륨 외에 UI 효과음과 환경음(Ambient) 조절용 슬라이더를 새롭게 추가 구성하고 오디오 소스 연동을 마무리함.
  - 오디오 믹서(AudioMixer)의 환경음 그룹 제어 변수명을 `AudioManager` 코드 설계에 부합하도록 `"AmbVolume"`으로 개칭 및 통일하여 볼륨 조작 오작동을 차단함.
  - PC 빌드 플랫폼 대응을 위해 설정 UI 내에 토글을 배치하여 풀스크린 모드와 창 모드 간 화면 비율을 동적으로 실시간 제어(`Screen.fullScreen`)할 수 있는 기능을 구축하고, 패널의 닫기 버튼 동작 연동을 완료함.
- **결과**: 볼륨 슬라이더 연동, 오디오 믹서 동기화 및 해상도/풀스크린 제어 기능이 탑재된 설정 시스템 구축 완료.
