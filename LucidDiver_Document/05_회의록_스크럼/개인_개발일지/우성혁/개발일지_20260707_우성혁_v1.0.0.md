## 🛠️ 트러블 슈팅 (선택)

### 1. 다중 비동기 씬 로드 시의 비정상적 로딩 UI 완료 현상
- **문제 상황**: `LevelDesignScene`과 `DemoScene`을 비동기로 동시에 병렬 로드할 때, 로딩 진척도가 다름에도 불구하고 `LevelDesignScene`의 로딩만 완료되면 로딩 씬(`LoadScene`)이 성급하게 종료되어 로딩 화면이 먼저 풀리는 오작동이 일어남.
- **발생 조건**: 기존 단일 신 로드 코드 상에서 사용하던 활성화 제어 속성(`allowSceneActivation`) 및 진행도(`progress`) 체크 구조가 하나의 신(LevelDesignScene)에만 귀속되어 있어 다른 신의 로딩 상태를 연산하지 못해 발생함.
- **해결 방법**: `DemoScene` 비동기 로딩 연산에도 동일한 `allowSceneActivation` 조작 및 `progress` 진행률 체크 제어를 반영하고, 두 신의 누적 진척도를 통합 계산해 로딩 UI 퍼센티지를 갱신하도록 처리하여 로딩 씬 라이프사이클을 보완함.

### 2. Additive 로딩 전환 후 세션 진입 시 무한 로딩 대기 현상
- **문제 상황**: 씬 로딩 구조 변경 후 인게임 세션 진입 과정에서 로딩 게이지가 정체된 채 다음 단계로 진행되지 않는 무한 로딩 먹통 현상이 발생함.
- **발생 조건**: 씬 로딩 명령 구조 중 일부의 `LoadSceneMode` 매개변수가 정합되지 않아 활성화 판단 루프에서 빠져나오지 못함.
- **해결 방법**: 병렬 비동기 씬 로드 시의 `LoadSceneMode` 매개변수를 양쪽 모두 명시적인 `LoadSceneMode.Additive` 모드로 일치시켜 해결함.

### 3. 타겟 씬 로딩 완료 후 로딩 UI(LoadScene)가 소멸되지 않는 현상
- **문제 상황**: 씬 로드 자체는 정상 완료되었으나 로딩 씬 화면이 계속 덮어 씌워진 채 해제되지 않음.
- **발생 조건**: 타겟 씬의 내부 활성화 및 정렬 처리가 온전히 수행되기 전에 로딩 씬의 `UnloadSceneAsync`를 성급하게 실행하여 호출이 엉켜 발생함.
- **해결 방법**: 추가 비동기 씬(`DemoScene`)의 활성화가 완벽히 완료되었음을 보장받은 직후 시점에만 `LoadScene`에 대한 언로드 명령이 예약되도록 시퀀스 순서를 정정함.

### 4. 로딩 씬 언로드 시 임시 스폰되었던 플레이어/에너미 오브젝트 동시 파괴 현상
- **문제 상황**: `LoadScene`이 최종적으로 언로드될 때, 해당 타이밍에 월드 상에 임시 생성되었던 중요 캐릭터(플레이어 및 적) 오브젝트들도 연쇄적으로 파괴되어 버리는 치명적인 사이드 이펙트 발생.
- **발생 조건**: 로딩을 대기하는 동안 스폰되었던 오브젝트들이 `Hierarchy` 계층구조상 소멸 예정인 `LoadScene` 하위 씬 공간 내부에 물리적으로 배정되어 발생함.
- **해결 방법**: 우선 `LoadScene` 내부의 로딩 연출용 UI 오브젝트 루트만 직접 비활성화하고, 임시 스폰된 캐릭터 오브젝트들은 즉각 `SceneManager.MoveGameObjectToScene` 메서드를 통해 로드된 실제 인게임 타겟 세션 씬(`targetScene`) 메모리 영역으로 강제 씬 이전 처리를 수행하여 안전하게 소멸 대상에서 분리 보호함.

### 5. 씬 이전 후 빌보드(Billboard) 및 카메라 정렬 오작동
- **문제 상황**: 스폰 오브젝트의 강제 씬 이동 및 UI 비활성화 조치 이후, 빌보드(Billboard) 각도가 카메라를 바라보지 않고 꺾이거나 고정되는 오류가 도출됨.
- **발생 조건**: 비동기 씬 로드 및 활성화, 로딩 UI 비활성화, 서브 씬 로딩이 진행되는 연쇄 프레임 지연 속에서 카메라 setup 정보(Camera.main) 캐싱에 순간 유실이 일어나 빌보드 `LateUpdate` 등에서 갱신되지 못해 발생함.
- **해결 방법**:
  - 로딩 라이프사이클 순서를 '타겟 씬 로드 완료 → 로딩 UI 비활성화 → 서브 Additive 씬 로딩' 순으로 명확히 동기화함.
  - 코루틴 내부의 `yield break;` 실행 위치를 모든 서브 Additive 씬 로딩이 완료된 시점 뒤로 지연 배치함.
  - [Billboard.cs](file:///c:/Woo_260126/UnityProject_LucidDiver/Assets/02_Scripts/Utils/Billboard.cs)의 `LateUpdate` 및 [PlayerMovement.cs](file:///c:/Woo_260126/UnityProject_LucidDiver/Assets/02_Scripts/System/Player/PlayerMovement.cs)의 `FixedUpdate`에서 메인 카메라의 존재 여부를 상시 점검하고 캐싱이 깨졌을 시 즉시 카메라를 재추적하도록 예외 보호 코드를 추가함.
  - [CameraSetupManager.cs](file:///c:/Woo_260126/UnityProject_LucidDiver/Assets/02_Scripts/Manager/GameSystem/CameraSetupManager.cs)를 통해 씬 병합이 최종 완료된 지점에 카메라 추적 대상 설정(`SetupCameraTarget`)을 재호출하도록 보강함.
