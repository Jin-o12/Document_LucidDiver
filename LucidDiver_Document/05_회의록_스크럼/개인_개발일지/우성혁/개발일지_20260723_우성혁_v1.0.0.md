## ✅ 완료한 작업

### 1. DOTween을 활용한 인게임 UI 애니메이션 구현
- **내용**:
  - **피격 HUD 흔들림 효과 (Shake)**: 플레이어 피격 시 게임플레이 HUD 오브젝트에 DOTween의 `DOShakePosition` / `DOShakeRotation` 기반 흔들림 연출을 적용함. 피격 이벤트 수신 시 HUD 트랜스폼에 단발성 Shake 시퀀스를 실행하여 컨트롤러 진동(햅틱)에 상응하는 시각 피드백을 제공함.
  - **팝업 UI 스케일 등장/소멸 애니메이션**: 인게임 신의 팝업 UI 창(인벤토리, 상자, 게임 메뉴, 설정, 로비 귀환 확인 팝업)에 `DOScale` 시퀀스를 적용하여 팝업 호출 시 0→1 스케일 확대 연출과 닫기 시 1→0 축소 연출을 구현함.
  - **ESC 키 & 닫기 버튼 통합 처리**: ESC 키 입력과 팝업 닫기 버튼 클릭 두 경로가 동일한 DOTween 닫기 애니메이션을 실행하도록 `UIManager`의 닫기 로직을 단일 메서드로 통합 수정함.
  - **Canvas Group Alpha Fade 연동**: 팝업의 `Canvas Group` 컴포넌트를 활용해 알파 값(`DOFade`)을 열기/닫기 시퀀스에 연계하여, 스케일 변화와 동시에 투명도가 0→1(등장) / 1→0(소멸)으로 부드럽게 전환되도록 구성함.
- **결과**: 피격 HUD Shake 및 팝업 스케일+Fade 복합 DOTween 애니메이션 적용 완료.
- **관련 파일**:
  - `UIManager.cs` (팝업 열기/닫기 통합 메서드 수정)
  - 각 팝업 UI 컨트롤러 스크립트 (인벤토리, 상자, 설정, 게임메뉴, 로비귀환 팝업)
- **포트폴리오 증거**: -

### 2. 팝업 출력 시 Global Volume Vignette 강도 변경 컨트롤러 추가
- **내용**:
  - 인게임 신에 배치된 `Global Volume`의 Post Processing 컴포넌트 중 `Vignette` 이펙트의 `Intensity` 값을 팝업 UI의 열기/닫기 상태에 연동하는 이벤트 컨트롤러를 신규 작성함.
  - 팝업 창이 열릴 때 Vignette Intensity를 증가시키는 이벤트를, 닫힐 때 원래 값으로 복원하는 이벤트를 각각 호출하여 팝업 활성화 중 화면 주변부가 어두워지는 집중 연출 효과를 부여함.
- **결과**: 팝업 출력 중 Vignette 강도 변화를 통한 포스트 프로세싱 연출 적용 완료.
- **관련 파일**:
  - `VignetteController.cs` (또는 신규 작성한 Global Volume 연동 이벤트 핸들러 스크립트)
