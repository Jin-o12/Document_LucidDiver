### 2. 플레이어 조작 추가 및 핵심 액션(달리기/구르기/스킬 입력) 구현
- **내용**:
  - **입력 바인딩 및 데이터 설정**: Input System 및 `LocalInputReader`에 달리기, 구르기, 스킬 입력을 매핑하고 `CharacterData`에 속도, MP 소모량, 쿨타임 등의 제어 지표를 추가함. 캐릭터 스폰 시 `SpawnManager`에서 데이터를 읽어 `PlayerStatus` 및 `PlayerInput`에 전달함.
  - **달리기 기능**: Left Shift 입력 유지 동안 작동하며, `PlayerStatus`에서 달리기 가능 여부 판단 후 `PlayerMovement`에서 MP를 소모(초당)하며 속도를 올림. MP 소진 시 달리기 불가 상태 코루틴(회복 시간 적용)을 작동함.
  - **구르기(회피) 기능**: 마우스 우클릭 입력 시 작동하며, `PlayerCombatPresenter`가 가능 여부를 확인한 후 `PlayerStatus`에서 MP를 소모하고 `PlayerMovement`가 구르기 속도와 상태 코루틴을 적용함. 구르기 상태 중에는 플레이어가 무적 판정(HP 감소 없음)을 받으며, 동작 시작 후 쿨타임 동안 재사용이 제한됨.
  - **스킬 입력 루트**: Q 키 입력 시의 전투 로직 호출 흐름을 연결하고 `PlayerCombatPresenter`에서 `Debug.Log` 호출 출력을 통한 연동 작동 여부를 검증함.
- **결과**: 인게임 내 플레이어 이동/전투 기본 액션 조작 및 시스템 연동 완료.
- **관련 파일**: Unity 클라이언트 조작/전투 관련 C# 스크립트군
- **포트폴리오 증거**: -
