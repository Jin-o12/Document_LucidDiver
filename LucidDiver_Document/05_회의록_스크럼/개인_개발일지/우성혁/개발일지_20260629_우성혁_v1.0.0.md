## ✅ 완료한 작업

### 1. 플레이 루프 깨짐 대응 및 재조립 (탈출/사망, 결과 UI, 로비 복귀)
- **내용**: 
  - 탈출 성공 시 결과 패널(ResultPanel)이 출력되지 않던 문제 해결을 위해 GameManager 내 `OnEscapeRequest += GameResult` 이벤트를 복구하여 탈출 성공 로직을 재활성화함.
  - 세이브 데이터가 존재할 때 DemoScene 재실행 시 캐릭터 데이터가 손상되는 문제 해결. DataManager의 `Awake` 단계에서 `SelectCharID`가 1로 고정되면서 메인 캐릭터 ID(101)를 덮어쓰는 호환성 이슈를 수정함.
  - 결과 확인 후 로비에서 재출격했을 때 결과 창이 정상적으로 출력되지 않던 문제 대응. ResultManager의 `OnDestroy` 메서드에서 인스턴스 파괴 코드를 주석 처리하여 추후 디버깅을 위해 보존하되 비활성화함.
  - 결과 창 UI의 계산 오류를 제거하기 위해 동조율 단계 상승 상태 판정 변수(`linkRateUp = memoryFragmentCount > 0 && extractionResult`)를 별도로 저장하여 분리 관리함. 또한, 탈출 실패 시에는 동조율이 상승하지 않도록 메서드 내부에서 탈출 성공 여부(bool)와 동조율 상승 로직을 연계 제어함.
- **결과**: 작업 병합 후 깨졌던 게임의 핵심 플레이 루프(탈출/사망 -> 결과 정산 및 UI 출력 -> 로비 복귀 -> 재출격)가 안정적으로 재조립되고 정상적으로 작동함.
- **관련 파일**: GameManager, DataManager, ResultManager 관련 스크립트 (Assets/02_Scripts/)
- **포트폴리오 증거**: -

### 2. 아이템 획득 제한 및 퀵슬롯 동기화 구현
- **내용**: 
  - 게임 내 밸런스 및 시스템 규칙에 맞추어 동일한 아이템을 특정 스택(최대 중첩 개수) 이상 획득하지 못하도록 제한하는 검사 코드(`if` 조건문)를 아이템 획득 로직에 추가함.
  - 인게임에서 아이템을 획득했을 때 퀵슬롯 UI가 실시간으로 갱신되지 않는 이슈 해결을 위해, 획득한 아이템의 TID를 퀵슬롯에서 조회하여 개수를 동기화하는 메서드를 추가함.
  - 실시간으로 동기화된 아이템 수량을 로비의 출격 준비 UI로 즉각 전달하는 연동 코드를 추가함.
- **결과**: 인벤토리 및 퀵슬롯 간의 실시간 개수 동기화가 보장되며, 최대 중첩 개수를 초과하는 비정상적인 아이템 획득이 제한됨.
- **관련 파일**: 아이템 및 퀵슬롯 관련 스크립트, 출격 준비 UI 스크립트
- **포트폴리오 증거**: -

### 3. 개인 심상 기록 UI 연출 형식 변경 및 스크립트 연동
- **내용**: 
  - 기존 텍스트 설명서 방식의 심상 기록 보기를 비주얼 노벨 연출 형식의 UI 양식으로 대폭 수정하고 관련 스크립트를 연동함.
  - 캐릭터 ID(Diver ID)를 기반으로 해당 캐릭터의 전용 대사 데이터를 조회하여 출력할 수 있도록 이벤트 변수 구조를 변경함.
  - 상황에 따른 유연한 연출을 위해 대사 인터페이스에 상황별 대사 총 개수를 구하는 기능 및 각 대사 인덱스의 TID를 추출하는 함수를 새롭게 설계/추가함.
  - UI 상의 좌우 이동 버튼 클릭을 통해 심상 기록 텍스트(대사)의 인덱스를 넘길 수 있도록 내비게이션 기능을 구현함.
  - 대사 내용에 어울리는 심상 기록 이미지를 유기적으로 변경할 수 있도록 스크립트에 이미지 오브젝트를 연결하고, 캐릭터 데이터를 참조하여 대사 창에 캐릭터명이 올바르게 표시되도록 연동함.
- **결과**: 단순 텍스트 나열에서 몰입감 있는 비주얼 노벨 스타일의 심상 기록 연출 UI로 업그레이드 완료.
- **관련 파일**: 심상 기록 UI, Dialogue 인터페이스 및 연동 스크립트
- **포트폴리오 증거**: -

## 🛠️ 트러블 슈팅 (선택)

1. **문제 상황**: 탈출 판정을 실행하여 결과 정산 시 `SaveCharacterData`가 `PlayerSaveData`에 정상적으로 생성되지 않는 현상 발생
   - `NullReferenceException: Object reference not set to an instance of an object`
   - `LobbyMainUI.Refresh ()` (at Assets/02_Scripts/UI/Lobby/LobbyMainUI.cs:73)
   - `LobbyMainUI.Start ()` (at Assets/02_Scripts/UI/Lobby/LobbyMainUI.cs:42)
2. **발생 조건**: 탈출 정산 후 메인 로비 UI가 갱신 및 시작되는 과정에서 발생
3. **해결 방법**: `LobbyMainUI`에서 세이브 데이터 관리를 담당하는 플레이어 정보 인터페이스 연결이 누락되었음을 확인하고, `saveRepo = new LocalSaveRepository();` 인스턴스 할당 코드를 추가하여 정상 연결함.

2. **문제 상황**: 세이브 데이터 저장 시 `myCharacters` 리스트가 정상적으로 생성되지 않아 참조가 불가능한 현상 발생
   - `NullReferenceException: Object reference not set to an instance of an object`
   - `LocalSaveRepository.GetLinkRateLevel ()` (at Assets/02_Scripts/System/LocalSaveRepository.cs:53)
2. **발생 조건**: 게임 시작 시 기존 저장 데이터를 로드하거나 동조율 레벨을 가져오는 등의 저장 데이터 참조 시 발생
3. **해결 방법**:
   - `LocalSaveRepository.LoadSaveData` 메서드 내부에서 역직렬화한 데이터(`JsonUtility.FromJson<PlayerSaveData>(json)`)가 내부 `playerSaveData` 필드에 정상적으로 할당되도록 코드를 수정함.
   - 이전 작업 과정에서 `SaveCharacterData` 구조체/클래스의 `[System.Serializable]` 선언이 유실되었던 것을 확인하고 이를 다시 추가하여 정상적으로 JSON 직렬화 및 리스트 저장이 가능하도록 조치함.
