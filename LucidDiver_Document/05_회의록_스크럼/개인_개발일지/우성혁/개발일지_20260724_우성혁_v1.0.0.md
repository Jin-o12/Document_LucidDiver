## 🛠️ 트러블 슈팅 (선택)

### 1. ESC 키를 반복 입력하여 메뉴 출력 시 메뉴 창 잔상이 화면에 남는 현상
- **문제 상황**: ESC 키를 연달아 반복 입력하여 게임 메뉴를 출력/닫을 때 화면에 메뉴 창 잔상이 지속 노출되고, 로비 UI 조작이 먹통이 되는 오작동 발생.
- **발생 조건 및 원인**:
  1. `LobbyUIPresenter`에서 메뉴 입력을 받아 `OpenPauseUI()` 메소드를 실행.
  2. `UIManager`에서 `Open<GameMenuUI>`를 호출해 `GameMenuUI` 출력.
  3. `GameMenuUI`가 출력된 직후 재차 GameMenu 입력 시 `OpenPauseUI`에서 `Close<GameMenuUI>` 메소드를 실행.
  4. `Close<GameMenuUI>` 처리 진행 중 또다시 `OpenPauseUI`가 실행되어 `CloseNowUI()`가 호출되고, 이로 인해 메인 바탕이 되는 현재 로비 UI까지 비활성화됨.
- **해결 방법**: UI 내비게이션 관리 스택 내 현재 활성화되어 있는 UI 오브젝트 개수가 1개뿐인 상황(바탕 로비 UI만 존재하는 상태)에서는 `CloseNowUI()`가 발동하지 않도록 방어 예외 조건을 추가함.
