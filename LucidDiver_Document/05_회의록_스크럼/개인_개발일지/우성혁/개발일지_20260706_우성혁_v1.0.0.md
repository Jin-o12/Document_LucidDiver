### 3. 플레이어 애니메이션 인게임 세션 적용
- **내용**: 
  - Dodge, Throw 애니메이션이 추가로 제작 적용된 `Yuan (Optimized) 1` 프리팹을 Characters 폴더에 생성 및 플레이어 프리팹으로 연결.
  - `AnimatorController` 및 `PlayerMovement` 스크립트에 `Evade` 파라미터를 추가하여 구르기 입력 시 애니메이션 연동.
  - `UseSkill` 파라미터를 추가하여 스킬 입력 시 애니메이션 연동 (이벤트를 통해 `SkillAnimate` 메소드가 호출되어 신호 전달).
  - 플레이어 피격 이벤트를 `PlayerMovement`에서 감지하여 애니포트레이트의 `Yuan_Hit_Face` 파라미터 값을 코루틴을 통해 제어함으로써 피격 애니메이션 구현.
- **결과**: 플레이어 기본 달리기, 구르기, 피격, 스킬(Throw) 애니메이션의 정상 인게임 재생 및 제어 로직 적용 완료.
- **관련 파일**:

  - [Yuan (Optimized) 1.prefab](UnityProject_LucidDiver/Assets/03_PreFabs/Characters/Yuan (Optimized) 1.prefab)
  - [Yuan-AnimController.controller](UnityProject_LucidDiver/Assets/05_Animations/Player/Yuan/Yuan-AnimController.controller)
