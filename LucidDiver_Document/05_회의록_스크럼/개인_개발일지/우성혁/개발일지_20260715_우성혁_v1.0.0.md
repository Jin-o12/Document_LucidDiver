## 🛠️ 트러블 슈팅 (선택)

### 1. 제한 시간 경과 루프 사운드 재생 중 다른 루프 사운드가 재생되면 이전 사운드가 소멸되는 현상
- **문제 상황**: 인게임 제한 시간 임박을 피드백해주는 경고 환경 루프 사운드가 정상 재생되고 있는 상태에서 캐릭터의 사망 루프 사운드 등 또 다른 루프 사운드가 트리거되는 순간, 기존에 울리던 제한 시간 루프 음원이 강제 종료되어 소리가 도중에 유실되는 현상 발생.
- **발생 조건 및 원인**: 단일 채널형 오디오 소스인 `SFXSource` 하나에 모든 루프성 사운드를 한꺼번에 몰아넣어 발생한 병목 현상으로, 오디오 소스 하나는 하나의 오디오 클립만 할당하여 연속 재생할 수 있어 이전 클립이 덮어쓰여 강제 소멸됨.
- **해결 방법**: `SFXSource`와 상호 독립적인 루프 재생이 가능하도록 전용 환경 사운드 소스인 `AmbSource`(환경 사운드 오디오 소스) 채널을 [AudioManager.cs](file:///c:/Woo_260126/UnityProject_LucidDiver/Assets/02_Scripts/Manager/Manager/AudioManager.cs) 내부에 추가하고, 기획 사운드 데이터 종류에 맞춰 `Ambient` 타입에 해당하는 소리는 이 `AmbSource` 채널을 통해 독립적으로 출력 및 중첩 재생되도록 오디오 소스 구분 처리를 완료함.
