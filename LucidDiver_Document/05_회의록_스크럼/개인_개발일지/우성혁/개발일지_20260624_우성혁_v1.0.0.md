### 5. 탈출 요청 및 탈출 성공/실패 전달 이벤트 수정
- **내용**:
  - 탈출 요청 이벤트 `OnEscapeRequest`를 `<int>` 기반(playerID 전달)에서 `<bool>` 기반(extractionResult 전달)으로 변경
  - 플레이어 `livingState`의 idle 상태 여부를 `PlayerStatus`의 Static 함수 `IsPlayerIdle`에서 관리하도록 수정
  - **5-A (탈출 성공)**: `GameManager`의 `StartEscape` 및 `StartEscapeTimer` 코드를 `ExitPoint`로 이동. `ExitPoint`에서 처리 후 `OnEscapeRequest` 이벤트를 발행하면 `GameManager`에서 `QuitGame`을 처리하는 구조로 개선
  - **5-B (탈출 실패)**: `GameManager`의 `GameOver` 코드를 `PlayerStatus`로 이동. `hpCurrent <= 0` 조건에서 `PlayerStatus`가 처리 후 `OnEscapeRequest` 이벤트를 발행하면 `GameManager`에서 `QuitGame`을 처리하는 구조로 개선
- **결과**: 이벤트 기반 아키텍처 정비 완료. 각 클래스의 책임이 명확해지고 GameManager의 역할이 경량화됨
- **관련 파일**: `GameManager.cs`, `ExitPoint.cs`, `PlayerStatus.cs`
- **포트폴리오 증거**: -
