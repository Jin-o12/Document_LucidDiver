## 1. 작업 개요

프로젝트 문서 폴더가 여러 버전의 기획서, 검수전 문서, UI 이미지, 시나리오 문서, 시스템 명세, 일정표, 스크럼 기록이 뒤섞인 상태였습니다.

이번 작업의 목표는 다음과 같습니다:
1. **P0 개발 기준 문서를 명확히 고정** (SSOT 확립)
2. **개발자가 봐야 할 문서와 참고만 해야 할 문서를 분리**
3. **구버전/검수전/중복 문서는 삭제하지 않고 Archive로 격리**
4. **서브컬처/시나리오/캐릭터 문서는 P0 범위를 확장하는 근거가 아닌 부록 문서로 명시**

## 4. 정리 원칙 요약

### SSOT 우선순위
1. **P0 정의서** (00_최종_P0_정의서.md) — 최상위 기준
2. **P0 시스템 명세서** (01_P0_시스템_명세서.md) — 시스템 동작 규칙
3. **P0 개발자 구현명세서** (02_P0_개발자_구현명세서.md) — 씬/매니저/변수/UI
4. **P0 일정표** (03_P0_일정표.md) / **P0 QA 체크리스트** (04_P0_QA_체크리스트.md)
5. **기획 부록 참고문서** (03_기획_부록/)
6. **UI 이미지 레퍼런스** (04_UI_이미지_레퍼런스/)
7. **Archive/Trash** (90_, 99_)

### 금지 사항
- 부록 문서(03_기획_부록/)를 근거로 P0 범위 확장 금지
- UI 이미지만 보고 6칸 퀵슬롯, 드래그&드롭 등을 구현 금지 (SSOT 우선)
- Archive 폴더 문서를 직접 수정 금지
