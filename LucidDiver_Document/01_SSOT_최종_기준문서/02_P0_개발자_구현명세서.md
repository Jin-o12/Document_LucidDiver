# P0 개발자 구현명세서

## 1. 씬(Scene) 플로우

```text
LobbyScene
  ├─ [출격 버튼] → SortiePreparePanel (LobbyScene 내 Panel)
  │    └─ [출격 확정 버튼] → GameScene (씬 전환)
  ├─ [다이버/기록 버튼] → DiverRecordPanel (LobbyScene 내 Panel)
  │    └─ [기록 01 선택] → MemoryLogPopup
  └─ [창고 버튼] → StorageInventoryPanel (LobbyScene 내 Panel)
       └─ [소지품 설정] → SortiePreparePanel (또는 인라인 슬롯 조작)

GameScene
  ├─ (플레이 중) → HP 0 감지 → ResultPanel (실패) 
  └─ (플레이 중) → 전화부스 충돌 → ResultPanel (성공)

ResultPanel (GameScene 내 또는 별도 씬)
  └─ [로비로 돌아가기] → LobbyScene (씬 전환)
```

---

## 2. 매니저 구조

| 매니저 | 담당 역할 | 생존 범위 |
|:---|:---|:---:|
| `GameManager` | 씬 플로우 제어, `sessionState` 전환 | 전역 (DontDestroyOnLoad) |
| `PersistentDataManager` | 저장 데이터 관리 (창고/동조율/기록 해금) | 전역 (DontDestroyOnLoad) |
| `SessionLootManager` | 세션 내 임시 획득 수량 관리 | 씬 한정 (GameScene) |
| `ResultManager` | 결과 정산 처리 및 UI 연동 | 결과창 Panel |
| `UIManager` (선택) | 패널 전환 및 UI 애니메이션 | LobbyScene 한정 |

## 3. 핵심 변수 목록

### 3.1 SessionLootData (씬 임시 / 세션 종료 후 소멸)

| 변수명 | 타입 | 설명 | 초기값 |
|:---|:---|:---|:---:|
| `memoryFragmentCount` | int | 세션 중 획득한 기억 파편 수 | 0 |
| `manaStoneCount` | int | 세션 중 획득한 마나석 수 | 0 |
| `potionCount` | int | 세션 중 획득한 회복약 수 | 0 |
| `playTime` | float | 세션 플레이 시간 (초) | 0f |
| `extractionResult` | bool | 탈출 성공 여부 (true=성공) | false |

### 3.2 PlayerProgressData (영속 저장 / SaveData)

| 변수명 | 타입 | 설명 | 초기값 |
|:---|:---|:---|:---:|
| `linkRateLevel` | int | 현재 동조율 단계 | 0 |
| `memoryLogUnlocked` | bool | 심상 기록 01 해금 여부 | false |
| `hasNewMemoryLog` | bool | 신규 기록 알림 여부 | false |

### 3.3 StorageData (영속 저장 / SaveData)

| 변수명 | 타입 | 설명 | 초기값 |
|:---|:---|:---|:---:|
| `storedManaStoneCount` | int | 창고 보관 마나석 총량 | 0 |
| `storedPotionCount` | int | 창고 보관 회복약 총량 | 0 |

### 3.4 QuickSlotData (영속 저장 / SaveData)

| 변수명 | 타입 | 설명 | 초기값 |
|:---|:---|:---|:---:|
| `equippedItemSlot1` | string | 슬롯 1번 아이템 ID | "" (비어있음) |
| `equippedItemSlot2` | string | 슬롯 2번 아이템 ID | "" (비어있음) |

## 4. 아이템 정산 규칙 (결정 사항)

### 4.1 기억 파편 (MemoryFragment)

```text
[탈출 성공 시]
  1. memoryFragmentCount > 0 이면:
     - linkRateLevel += 1
     - memoryLogUnlocked = true  (기록 01 해금)
     - hasNewMemoryLog = true    (NEW 알림 활성화)
  2. 결과창에 "기억 파편 자동 소모" 고지 표시
  3. memoryFragmentCount는 사용 후 소멸 (창고 저장 없음)

[탈출 실패 시]
  1. memoryFragmentCount = 0 (전량 유실)
  2. linkRateLevel 변동 없음
  3. memoryLogUnlocked 변동 없음
```

> [!WARNING]
> 기억 파편은 창고/인벤토리에 저장되지 않습니다.
> 아이템 슬롯, 드롭 아이템 UI에서 기억 파편 수량 표시만 허용됩니다.
> "창고에 기억 파편이 있음" 또는 "기억 파편을 꺼냄"은 P0 구현 범위가 아닙니다.

### 4.2 마나석 / 회복약 (소모품)

```text
[탈출 성공 시]
  - storedManaStoneCount += manaStoneCount
  - storedPotionCount += potionCount
  - 결과창에 누적 저장 수량 표시

[탈출 실패 시]
  - manaStoneCount = 0 (유실)
  - potionCount = 0 (유실)
  - 창고 누적치 변동 없음
```

### 4.3 소모품 사용 (인게임)

```text
[마나석 사용]
  - playerMana += 회복량 (예: +30)
  - 세션 내 manaStoneCount -= 1

[회복약 사용]
  - playerHP += 회복량 (예: +30)
  - 세션 내 potionCount -= 1
```

> [!NOTE]
> 소모품 사용은 P0 필수 구현이나 개발 부담 시 "창고 저장/슬롯 장착 표시"만 구현 가능.
> 이 경우 PM에게 통보 후 P0 완료 체크리스트에서 해당 항목을 조건부 통과 처리.

## 6. 개발 우선순위

```
[1순위] 씬 전환 플로우 (로비 ↔ 출격준비 ↔ 게임씬 ↔ 결과창)
[2순위] 플레이어 이동/조준/공격 (WASD + 마우스)
[3순위] 적 1종 추적/공격 AI
[4순위] 아이템 3종 충돌 획득 (기억 파편, 마나석, 회복약)
[5순위] 전화부스 탈출 / HP 0 강제 각성
[6순위] 결과창 정산 (성공/실패 분기, 자동 소모, 창고 저장)
[7순위] 로비 UI (동조율, 다이버 기록, 창고)
[8순위] 소모품 퀵슬롯 장착 및 다음 출격 반입
[9순위] 소모품 인게임 사용 (마나/HP 회복)
[P0.5] NEW 알림, 기록 해금 연출, 결과창 애니메이션
```
