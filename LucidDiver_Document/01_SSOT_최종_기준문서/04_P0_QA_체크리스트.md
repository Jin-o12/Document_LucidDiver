## 4. 결과 정산 테스트 (필수 시나리오)

### 4.1 시나리오 A: 성공 루트 (기억 파편 보유 + 탈출 성공)

**전제 조건**: 기억 파편 1개 이상 획득 후 전화부스 탈출 성공

| # | 확인 항목 | 기대 결과 | 결과 | 이슈 |
|:---:|:---|:---|:---:|:---|
| A-01 | ResultPanel 성공 배너 | "탈출 성공" 배너 표시 | ☐ | |
| A-02 | 기억 파편 자동 소모 고지 | 소모 개수 + "자동 소모" 텍스트 | ☐ | |
| A-03 | 동조율 단계 상승 표시 | Lv.X → Lv.(X+1) 표시 | ☐ | |
| A-04 | memoryLogUnlocked = true | 기록 해금 알림 표시 | ☐ | |
| A-05 | 마나석 창고 저장 수 표시 | 획득 수량만큼 저장 표시 | ☐ | |
| A-06 | 회복약 창고 저장 수 표시 | 획득 수량만큼 저장 표시 | ☐ | |
| A-07 | 귀환 성공 대사 출력 | 탈출 성공 전용 대사 | ☐ | |
| A-08 | [로비로 돌아가기] → LobbyScene | 로비 복귀 정상 | ☐ | |

### 4.2 시나리오 B: 실패 루트 (아이템 보유 + HP 0 사망)

**전제 조건**: 기억 파편, 마나석, 회복약 각 1개 이상 보유 후 HP 0 사망

| # | 확인 항목 | 기대 결과 | 결과 | 이슈 |
|:---:|:---|:---|:---:|:---|
| B-01 | ResultPanel 실패 배너 | "강제 각성" 배너 표시 | ☐ | |
| B-02 | 기억 파편 유실 고지 | 유실 처리 텍스트 | ☐ | |
| B-03 | 동조율 변화 없음 | linkRateLevel 동일 확인 | ☐ | |
| B-04 | memoryLogUnlocked 변화 없음 | 기록 해금 없음 확인 | ☐ | |
| B-05 | 마나석/회복약 유실 표시 | 획득 수량 0 표시 | ☐ | |
| B-06 | storedManaStoneCount 변동 없음 | 창고 수량 동일 확인 | ☐ | |
| B-07 | storedPotionCount 변동 없음 | 창고 수량 동일 확인 | ☐ | |
| B-08 | 강제 각성 귀환 대사 출력 | 실패 전용 대사 | ☐ | |

### 4.3 시나리오 C: 창고 → 소지품 슬롯 → 출격 반입

**전제 조건**: storedManaStoneCount >= 1 또는 storedPotionCount >= 1

| # | 확인 항목 | 기대 결과 | 결과 | 이슈 |
|:---:|:---|:---|:---:|:---|
| C-01 | 창고에서 마나석/회복약 보관 수량 표시 | 정확한 수량 표시 | ☐ | |
| C-02 | 소지품 슬롯 1번에 아이템 장착 | equippedItemSlot1 설정 | ☐ | |
| C-03 | 소지품 슬롯 2번에 아이템 장착 | equippedItemSlot2 설정 | ☐ | |
| C-04 | 출격 준비 화면에서 장착 아이템 확인 | 슬롯에 아이콘 표시 | ☐ | |
| C-05 | 출격 → GameScene 진입 | 퀵슬롯 2칸에 장착 아이템 로드 | ☐ | |

### 4.4 시나리오 D: 다이버 기록 열람

| # | 확인 항목 | 기대 결과 | 결과 | 이슈 |

## 6. P0.5 착수 조건 판단 기준

> [!IMPORTANT]
> 07.11(금) 기준 아래 조건을 모두 충족해야만 P0.5 착수가 가능합니다.

**필수 조건:**
- [ ] 시나리오 A, B, C, D 전체 연속 3회 오류 없이 통과
- [ ] 데이터 영속성 테스트 전체 통과
- [ ] 씬 플로우 테스트 전체 통과

**미충족 시:**
- P0.5 선택 구현 전부 폐기
- 신규 기능 추가 금지
- 버그 수정 및 발표 안정화에만 집중

**충족 시:**
- P0.5 항목 중 발표 효과가 큰 1~2개만 선택
- CP/PM 승인 후 진행
