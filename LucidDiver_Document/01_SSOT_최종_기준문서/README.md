## 사용 지침

### 개발자 (TD: 강다영)
1. `00_최종_P0_정의서.md` → P0 구현 범위 확인
2. `01_P0_시스템_명세서.md` → 각 시스템 동작 규칙 확인
3. `02_P0_개발자_구현명세서.md` → 씬, 매니저, 변수, UI 구현 사양 확인
4. `02_개발_전달용/P0_기능_티켓_목록.md` → 작업 티켓 확인

### 기획 PM (PM: 송예찬)
1. `03_P0_일정표.md` → 일정 및 마일스톤 확인
2. `04_P0_QA_체크리스트.md` → 테스트 항목 관리
3. `02_개발_전달용/P0_데이터_변수표.md` → 변수명 일관성 확인

### CP (CP: 장수영)
1. `00_최종_P0_정의서.md` → P0/P0.5/제외 범위 최종 확인
2. `03_P0_일정표.md` → 전체 일정 현황 파악
